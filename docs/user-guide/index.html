NeQOS User Guide¶

Start with How NeQOS works for the architecture and terminology, then follow the installation, configuration and execution chapters for a first run. Use Built-in protocol catalog to select an operation and inspect its declared inputs, defaults and outputs. The API Reference covers driver task surfaces and protocol implementation stages.

Already using 0.5.0? Start with Move from 0.5.0 to 0.6.0. For current launch commands, choose Run without a browser or Operate from a browser.

Important

Use matching NodeEngine, DeviceOS, contracts and examples for this release. Before operating hardware, check example optical powers, attenuation, serial numbers and detector wiring against your network.

Which component does what?¶

  • DeviceOS runs on the host connected to a device and hosts its DeviceEngine and hardware driver. The driver declares the device’s task surface; the DeviceEngine exposes it, admits and schedules device tasks, and reports their lifecycle.

  • NodeEngine coordinates the configured devices (across inventory nodes in inventory mode), schedules protocols, manages device leases and writes the execution record.

  • The network description (network.json) declares device identities, endpoints, channels, link roles and physical limits. Inventory mode separates stable equipment from the experiment’s topology and operating settings; see Describe the network.

  • The run plan (input.json) selects a library and an ordered list of protocols with their input overrides. It does not replace the network description.

  • The built-in catalog ships with NodeEngine. An Open library adds external protocol definitions and, when needed, Python handlers.

Execution and scientific quality¶

Successful execution means that the declared operations completed. It does not by itself certify acceptable optical alignment, detector health without an enabled guard, or useful quantum-state quality. Read the measured observations, guard evidence and scientific metrics, not only the terminal state.

The built-in protocol catalog lists callable protocols and their input and output contracts. For Open libraries and composition handlers, see NodeEngine API.

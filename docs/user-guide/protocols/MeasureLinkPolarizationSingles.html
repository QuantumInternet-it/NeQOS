MeasureLinkPolarizationSingles¶

Measures finite singles counts and rates across logical analyzer states for one or more analyzer-equipped target links. network.json declares each channel as polarizer or PBS: complementary PBS outputs are acquired together, reducing physical settings without changing the reported logical states. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

Catalog location: link.characterization. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running¶

Read 1. Install the software, 2. Describe the bench and 4. Run and customize a protocol. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

Runtime property

Declared value

Resource requests

[“$shared.resourceDeviceIds”]

Distributed examples¶

Run input: input.json. Contains 1 direct step(s) for this protocol.

Network template: network.json. Edit host addresses, serials, roles and physical channels before hardware use.

The downloadable input is an editable template. Presence of a parameter in it is not proof that every option or branch was tested.

python NodeEnginePack/NodeEngine.py \
  --licenseFile "./config/license.json" \
  --configFile "./NodeEnginePack/ReservedMetaProtocols/link/characterization/MeasureLinkPolarizationSingles/RunExample/network.json" \
  --nodeId "ExampleNodeId" \
  --metaProtocolRun "./NodeEnginePack/ReservedMetaProtocols/link/characterization/MeasureLinkPolarizationSingles/RunExample/input.json" \
  --waitProtocol --verboseRunFolders

This command is for a source checkout. With an executable distribution, replace the Python/script prefix with your NodeEngine executable and retain the flags; see 1. Install the software for shell-specific syntax.

Complete input reference¶

These entries are generated from inputSchema.parameters and sharedParams, including nested objects and array items. Required means the effective value must satisfy the declared contract; a usable catalog default can already supply it. A required value whose default is null normally needs an override. Null is a JSON value, not a synonym for omission.

Nested defaults are shown only when present in the catalog’s default object. No declared nested default does not imply that an omitted parent object is valid. Example coverage means serialized presence in a direct run-plan step, not hardware coverage. Runtime cross-field and network checks are described by the contract text and 4. Run and customize a protocol; the flat schema is not a discriminated union.

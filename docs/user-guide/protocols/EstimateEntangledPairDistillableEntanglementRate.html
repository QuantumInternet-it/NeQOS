EstimateEntangledPairDistillableEntanglementRate¶

entanglement.distillation

Estimate detected pair throughput and a one-way hashing lower bound from existing tomography.

foreground timeout 5 min

Lease: no device resources.

Estimates detected pair throughput and a best-direction one-way hashing lower bound in ebit per pair and ebit per second from an existing two-qubit density matrix and background-corrected tomography, without acquisition or physical distillation.

1 Minimal run¶

Input

Type

Meaning

twoQubitDensityMatrix

object

Declared output object from ReconstructTwoQubitDensityMatrix containing rho in |00>, |01>, |10>, |11> order.

entangledPairPolarizationTomography

object

The same source observation used for reconstruction: measurementDurationSec per projection and correctedCountsByProjection. Sum complete HV, DA and RL outcomes, divide each sum by the per-projection duration (not the whole scan duration) and average the three rates; works for polarizer and PBS readouts.

2 What you get¶

Export key

Content

entanglement.distillation.estimate.distillableEntanglementRate

Detected background-corrected pair rate, three complete-basis rates and dispersion, subsystem entropies, directional coherent informations, best direction, hashing lower bound and detected ebit/s lower bound.

entanglement.distillation.artifact.distillableEntanglementRateReport

Detailed JSON report.

entanglement.distillation.artifact.distillableEntanglementRateCompactReport

Markdown throughput summary and scientific caveat.

entanglement.distillation.artifact.distillableEntanglementRatePlots

Matching PNG/SVG detected-rate and directional hashing-bound plots.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under outputs in result.json; see 6. Read results and diagnose failures.

5 How it is built¶

Implemented directly by the bound stages.

Technical details

Contract: protocol.json.

Source: NodeEnginePack/ReservedMetaProtocols/entanglement/distillation/EstimateEntangledPairDistillableEntanglementRate/protocol.json.

Handler source: NodeEnginePack/ReservedMetaProtocols/entanglement/distillation/EstimateEntangledPairDistillableEntanglementRate/Handlers.py.

Submission and waiting API.

Catalog defaults:

{
  "twoQubitDensityMatrix": null,
  "entangledPairPolarizationTomography": null,
  "densityTolerance": 1e-09
}

Stages, in declared order:

[
  {

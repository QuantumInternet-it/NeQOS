AlignChannels¶

timing.alignment

Measure relative channel timing offsets and optionally apply the derived input delays.

foreground timeout 30 min

Lease: no device resources.

Measure correlations from a reference channel to target channels, estimate their relative timing offsets, and optionally apply the derived input delays.

1 Minimal run¶

Input

Type

Meaning

timeTaggerDeviceId

string length >= 1

Identifier of the Time Tagger that measures and optionally corrects the channels.

referenceChannel

integer >= 1

Physical channel used as the temporal reference.

targetChannels

integer[] (items >= 1)

Physical channels aligned to the reference channel.

targetChannels[]

integer >= 1

Physical Time Tagger channel number.

 
{
  "schemaVersion": "0.4",
  "metaProtocolLibrary": {
    "libraryId": "neqos-protected"
  },
  "steps": [
    {
      "protocolId": "AlignChannels",
      "sharedParams": {
        "timeTaggerDeviceId": "ExampleTimeTaggerId",
        "referenceChannel": 8,
        "targetChannels": [
          2,
          3,
          4,
          5
        ]
      }
    }
  ]
}

Download minimal input.json

Network: network.json.

python NodeEnginePack/NodeEngine.py \
  --licenseFile "./config/license.json" \
  --configFile "./network.json" \
  --nodeId "ExampleNodeId" \
  --metaProtocolRun "./input.json" \
  --waitProtocol --verboseRunFolders

See How to run a protocol for launch setup, defaults, null handling and runtime conditions.

2 What you get¶

Export key

Content

timing.alignment.observation.channelAlignment

Measured correlations, selected peak estimates, and per-channel alignment outcomes.

timing.alignment.observation.correlations

Correlation records indexed by reference-to-target measurement key.

timing.alignment.applied.channelDelays

Initial live baseline plus planned, read-back, and applied Time Tagger input delays.

timing.alignment.artifact.histogramPngByCorrelation

NodeEngine-local PNG diagnostic path for each coarse, fine, or single alignment histogram.

timing.alignment.artifact.histogramSvgByCorrelation

NodeEngine-local SVG diagnostic path for each coarse, fine, or single alignment histogram.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under outputs in result.json; see 6. Read results and diagnose failures.

3 Options¶

Input

Default

Allowed

Meaning

acquisition

structured value (see Technical details)

—

Correlation acquisition passes and histogram settings.

acquisition.mode

“coarseFine”

“single” | “coarseFine”

Acquisition workflow. With coarseFine and delayCorrection.apply=false, acquisition.single is used for one measurement-only pass. Required when the containing object or array item is supplied.

acquisition.clear

true

—

Clear measurements before acquisition. Required when the containing object or array item is supplied.

acquisition.single

{“binCount”: null, “binWidthPs”: 10, “durationSec”: 30}

—

Single-pass acquisition settings. Required only for acquisition.mode=’single’ or delayCorrection.apply=false; unused otherwise.

30

—

Integration duration in seconds. Required when the containing object or array item is supplied.

>= 1

Histogram bin width in picoseconds. Required when the containing object or array item is supplied.

null

>= 1

Histogram bin count; if null, acquisition.pumpFrequencyMHz is required to derive it.

—

>= 1

Histogram bin width in picoseconds. Required when the containing object or array item is supplied.

acquisition.coarse.binCount

null

>= 1

Histogram bin count; if null, acquisition.pumpFrequencyMHz is required to derive it.

acquisition.fine

{“binCount”: null, “binWidthPs”: 10, “durationSec”: 30}

—

Fine verification acquisition settings.

acquisition.fine.durationSec

30

—

Integration duration in seconds. Required when the containing object or array item is supplied.

acquisition.fine.binWidthPs

10

>= 1

Histogram bin width in picoseconds. Required when the containing object or array item is supplied.

acquisition.fine.binCount

null

>= 1

Histogram bin count; if null, acquisition.pumpFrequencyMHz is required to derive it.

acquisition.pumpFrequencyMHz

null

>= 0

Pump frequency used to derive any omitted bin counts; required whenever the selected pass has binCount null.

delayCorrection

{“apply”: true, “basePs”: null, “settleSec”: 0.2, “sign”: 1}

—

Policy for applying estimated input delays after reading the live Time Tagger baseline.

delayCorrection.apply

true

—

Apply estimated offsets as Time Tagger input delays. Required when the containing object or array item is supplied.

delayCorrection.sign

1

—

Sign applied to each estimated offset. Required when the containing object or array item is supplied.

delayCorrection.basePs

null

—

Optional common input-delay baseline in picoseconds.

delayCorrection.settleSec

0.2

>= 0

Delay after applying a correction round, in seconds. Required when the containing object or array item is supplied.

peakSelection

structured value (see Technical details)

—

Rules used to choose and qualify correlation peaks.

peakSelection.mode

“dominant”

“dominant” | “rank” | “index” | “nth” | “closest” | “nearest”

Rule used to select a correlation peak. Required when the containing object or array item is supplied.

peakSelection.rank

1

>= 1

Rank used by ranked selection modes. Required only for rank/index/nth selection; unused for other modes.

peakSelection.targetDelayPs

null

—

Target delay used by nearest-peak selection. Required for closest/nearest selection; there is no dominant-peak fallback.

peakSelection.rejectCenterPs

null

—

Centre of an excluded delay interval.

peakSelection.rejectHalfWidthPs

null

—

Half width of an excluded delay interval.

peakSelection.gaussianFitMinRelativeHeight

0.2

>= 0

Minimum relative height for local Gaussian fitting. Required when the containing object or array item is supplied.

peakSelection.gaussianFitMaxHalfWidthPs

null

—

Optional maximum half-width for local Gaussian fitting.

peakSelection.diagnosticMaxPeaks

20

>= 0

Maximum locally selected diagnostic peaks to retain; zero retains all after minSeparationPs filtering. Required when the containing object or array item is supplied.

peakSelection.minSeparationPs

100

>= 0

Minimum separation between diagnostic peaks in picoseconds. Required when the containing object or array item is supplied.

peakSelection.minCoincidences

1

>= 0

Minimum coincidences required for a selected peak. Required when the containing object or array item is supplied.

5 How it is built¶

Declared submit sequence: ReadChannelDelays.

Handler-submitted children (may be conditional or repeated):

  • MeasureCorrelations

  • ApplyChannelDelays

Technical details

Contract: protocol.json.

Source: NodeEnginePack/ReservedMetaProtocols/timing/alignment/AlignChannels/protocol.json.

Handler source: NodeEnginePack/ReservedMetaProtocols/timing/alignment/AlignChannels/Handlers.py.

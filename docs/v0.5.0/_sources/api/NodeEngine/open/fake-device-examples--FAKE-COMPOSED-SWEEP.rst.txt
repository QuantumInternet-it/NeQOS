FAKE-COMPOSED-SWEEP
===================

Library: ``fake-device-examples``

Hardware-free root meta-protocol. It submits one branch which submits a configurable number of leaf runs from the same stage.

:bdg:`foreground` :bdg:`timeout 30 s`

**Lease:** ``$shared.fakeDeviceId``.

FAKE-SIMPLE
===========

Library: ``fake-device-examples``

Very small FakeDriver foreground protocol: set the gain, then run a short synchronous task.

:bdg:`foreground` :bdg:`timeout 30 s`

**Lease:** ``FakeDeviceId``.

1 Required inputs
-----------------

Catalog defaults satisfy the input schema; no input overrides are required.

:doc:`Input defaults and launching </user-guide/running>`.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - ``summary.status``
     - Terminal status returned by the foreground check.
   * - ``summary.deviceId``
     - FakeDriver device used by the run.
   * - ``summary.gain``
     - Gain confirmed by the SetGainTask.
   * - ``summary.durationSec``
     - Duration confirmed by the foreground check in seconds.

Declared keys are present after successful completion; values may be null or empty. See :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``fakeDeviceId``
     - "FakeDeviceId"
     - length >= 1
     - Identifier of the shared FakeDriver device.
   * - ``gain``
     - 2.5
     - >= 0
     - Synthetic gain set before the foreground task.
   * - ``taskDurationSec``
     - 1.0
     - >= 0
     - Foreground task duration in seconds.
   * - ``tickSec``
     - 0.5
     - >= 0
     - FakeDriver task tick interval in seconds.

Any traffic-mode change is first protected at declared source/attenuator maxima; it then parks the sources, composes MeasureLinkCoincidences for the requested pairs, and restores the exact live state. The source and TimeTagger leases remain owned for the complete park/acquire/restore bracket, including failure cleanup. Optional detectorPairs select physical reference-target channels validated against network bindings, including PBS/multibranch ports; these pairs are acquired together through MeasureCoincidences. latchGuard is forwarded unchanged, with the exact selected health-guard lease union.

tomography.state/ReconstructTwoQubitDensityMatrix¶

ReconstructTwoQubitDensityMatrix¶

Reconstructs a physical two-qubit density matrix from a complete background-corrected H/V/D/A/R/L coincidence observation. It preserves the unconstrained linear-inversion estimate as a diagnostic and fits a positive semidefinite trace-one matrix by maximum likelihood. The result is a reconstructed state, not a fidelity metric: downstream protocols may compare it with a target state or derive quality estimates without repeating tomography.

Stage handler runtime¶

A handler receives ctx and its effective params. Import these public helper types from NodeEnginePack.NodeEngineAuxiliary; the compiled distribution supplies this module.

Write a meta-protocol for complete static and dynamic examples.

protocolId identifies this run; protocolTemplateId identifies its definition. stageIndex is zero-based. scratchpad persists across stages and requeues. lastStageResults is the earlier stage history; taskResults collects this handler invocation’s device/import/publication results. nodeEngine is the runtime object, not an invitation to depend on private engine internals.

Scratchpad and local observations¶

logger

def logger() -> logging.Logger

The NodeEngine logger; no await is needed.

get

def get(key: str, default=None)

Read a scratchpad key or dotted dictionary path. A literal matching key takes precedence; missing paths return default. This does not read sharedParams or child exports.

set

def set(key: str, value: Any) -> None

Store a scratchpad value. Dotted paths create nested dictionaries. Use consistent namespaces: if an intermediate path is already a non-object, this method falls back to a literal key rather than replacing it.

local_telemetry

def local_telemetry(deviceId: str) -> Dict[str, Any]

Read the latest cached local telemetry for a device. It may be empty or stale: this is not an awaited live device read.

local_device_config

def local_device_config(deviceId: str) -> Dict[str, Any]

Read the local device’s network-description entry. Returns an empty object for an unknown local device.

Child protocols¶

submit_microprotocol

def submit_microprotocol(templateId: str, *, sharedParamOverrides: Optional[Dict[str, Any]]=None, commonStageParams: Optional[Dict[str, Any]]=None, stageParamOverrides: Optional[Dict[str, Dict[str, Any]]]=None, resourceRequests: Optional[List[str]]=None, initialScratchpad: Optional[Dict[str, Any]]=None, artifactIterationIndex: Optional[int]=None, artifactOperationIndex: Optional[int]=None) -> str

Submit a child and return its runtime ID immediately; do not await this method. The child’s input overrides are validated and its parent relationship is recorded. resourceRequests=None uses the child’s declaration; an explicit list replaces it. initialScratchpad is copied. Optional artifact iteration/operation indices affect child artifact naming, not execution or input validation.

microprotocol_state

def microprotocol_state(runtimeId: str) -> Optional[str]

Return the child’s current state name, or None for an unknown runtime ID. A template ID is not a runtime ID.

microprotocol_succeeded

def microprotocol_succeeded(runtimeId: str) -> bool

True only for COMPLETED; False for unknown or non-completed runs.

microprotocol_failed

def microprotocol_failed(runtimeId: str) -> bool

True for FAILED or ABORTED; False for unknown runs. Check microprotocol_state for None before polling.

child_output

def child_output(runtimeId: str, path: str) -> Any

Read a declared export from a COMPLETED child and return a defensive copy. A nested dictionary path below a declared object export is allowed if the value exists. Unknown, non-completed, undeclared or missing paths raise ValueError. Do not read a child’s private scratchpad or microProtocolInstances.

abort_microprotocol

async def abort_microprotocol(runtimeId: str, reason: str='STAGE_ABORT') -> Dict[str, Any]

Await an abort request for a child. Inspect the returned reply; requesting abort is not successful completion or an imported result.

Device operations¶

run_task

async def run_task(deviceId: str, taskName: str, params: Optional[Dict[str, Any]]=None) -> Dict[str, Any]

Await one device task. Records and returns the normalized reply, including status, result, errorType, errorMessage and reply. Check status == ‘OK’ and any task-specific result status before consuming the payload.

run_parallel

async def run_parallel(tasks: List[TaskCall]) -> List[Dict[str, Any]]

Await a list of TaskCall requests. Records every reply; inspect every result for errors. Device scheduling and leases still apply, so parallel requests do not guarantee simultaneous hardware acquisition.

set_parameter

async def set_parameter(deviceId: str, name: str, value: Any) -> Dict[str, Any]

Await a device parameter write and record its normalized reply. Check the reply and the device-specific read-back contract.

get_parameter

async def get_parameter(deviceId: str, name: str) -> Dict[str, Any]

Await a device parameter read and record its normalized reply.

read_signal

async def read_signal(deviceId: str, name: str) -> Dict[str, Any]

Await a named driver signal and record its normalized reply.

pull_device_file

async def pull_device_file(deviceId: str, sourcePath: str, destinationDirectory: str, *, fileName: Optional[str]=None, expectedSizeBytes: Optional[int]=None, expectedSha256: Optional[str]=None) -> Dict[str, Any]

Await a device artifact transfer. Optional size and SHA-256 expectations verify the transferred file; this call records a PullDeviceFile result and returns the transfer result, not a run_task envelope.

Terminal cleanup¶

register_terminal_cleanup_task

def register_terminal_cleanup_task(deviceId: str, taskName: str, params: Optional[Dict[str, Any]]=None) -> None

Register an idempotent executeTask compensation for reversible device state. This does not execute it now; see the cleanup section in the authoring guide.

clear_terminal_cleanup_task

def clear_terminal_cleanup_task(deviceId: str, taskName: str, params: Optional[Dict[str, Any]]=None) -> None

Remove the matching normalized deviceId/taskName/params registration only after the restoring task succeeds. Matching uses object equality, not just taskName.

register_terminal_cleanup_action

def register_terminal_cleanup_action(action: Dict[str, Any]) -> None

Register an executeTask or setParameter compensation. A setParameter action contains parameterName and value, with optional expectedReadBack. Identical normalized registrations are deduplicated and persisted in run-manifest.json.

clear_terminal_cleanup_action

def clear_terminal_cleanup_action(action: Dict[str, Any]) -> None

Remove an action matching the complete normalized registration. This only clears the registration; it does not restore device state.

Decision

Effect

advance

Continue with the next stage; after the last stage the run completes.

repeat

Run this stage again inside the running protocol; optional delaySec sleeps before repeating.

requeue

Return to scheduling at the same stage; optional delaySec delays eligibility. Prefer this while waiting for children.

complete

Complete early, skipping later stages. A parent cannot complete while a descendant is non-terminal. Publish required outputs before completing.

fail

Fail this protocol with reason; descendant abort and terminal lease cleanup follow the engine lifecycle.

delaySec is optional and non-negative. A decision string is accepted for compatibility; return StageResult to specify a reason, delay or lease policy. An invalid decision or an unhandled handler exception fails the stage.

On requeue, owned and delegated leases are retained by default. releaseResources=True explicitly yields them; do not use it while preserving an atomic sequence of child operations. retainResources is the older compatibility field, not required to retain an existing lease root. Release flags have no repeat/advance meaning.

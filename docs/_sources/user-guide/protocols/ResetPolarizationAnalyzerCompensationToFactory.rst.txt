ResetPolarizationAnalyzerCompensationToFactory
==============================================

``device.calibrationStore``

Replace an analyzer compensation table with its factory tomography states.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** devices selected by ``deviceId``.

Replaces one analyzer channel's compensated table with its six applied factory states at the configured wavelength, optionally persists it on DeviceOS, and applies a selected final state.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``channel``
     - 1
     - >= 1
     - Analyzer channel; MPC320 supports channel 1.
   * - ``persist``
     - true
     - —
     - Also overwrite DeviceOS-local persisted calibration; false changes only the active table.
   * - ``finalTomographyState``
     - "H"
     - "H" \| "V" \| "D" \| "A" \| "R" \| "L"
     - Factory-equivalent state applied after installation; the analyzer must already have the correct link wavelength. Factory capture moves through all six states.

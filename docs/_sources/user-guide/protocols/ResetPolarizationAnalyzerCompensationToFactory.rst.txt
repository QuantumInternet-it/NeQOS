ResetPolarizationAnalyzerCompensationToFactory
==============================================

Replaces one analyzer channel's compensated table with its six applied factory states at the configured wavelength, optionally persists it on DeviceOS, and applies a selected final state.

Catalog location: ``device.calibrationStore``. This page documents the current exported Reserved contract, not a hardware-test certificate.

EstimateEntangledPairFidelity
=============================

Estimates Phi+ lab-frame fidelity, the fully entangled fraction over local unitary frames, and their fidelity gap from a physical two-qubit density matrix without acquiring data or changing hardware.

Outputs and evidence

   * - Export key

   * - ``entanglement.fidelity.estimate.entangledPairFidelity``
     - estimate / object
     - Dimensionless state metrics in [0,1]: labFrameFidelity is the Phi+ overlap in the current laboratory frame; fullyEntangledFraction is the SVD maximum overlap over all maximally entangled two-qubit states, invariant under local unitaries; frameMisalignmentFidelityLoss is fullyEntangledFraction minus labFrameFidelity (clamped at zero for roundoff), ideally recoverable by local unitary compensation. targetStateDefinition fixes Phi+ = (HH + VV) / sqrt(2). crossCheck.fullyEntangledFractionNumeric and crossCheck.numericLocalUnitary contain the independent numerical optimization, without a delta field. svdLocalUnitary records method=svd and the correlation/singular-value diagnostics. No metric implies a correction applied to hardware or identifies the physical cause of a fidelity deficit. numericLocalUnitary retains only bestAttempt and attemptCount, plus unitaryA, unitaryB and rhoOptimized for that best attempt; matrices use real/imag payloads and the stated dagger transformation. Full restart histories are not exported.

     - artifact / string
     - Path to the detailed JSON fidelity report.
   * - ``entanglement.fidelity.artifact.entangledPairFidelityCompactReport``
     - artifact / string

     - artifact / object

     - artifact / object

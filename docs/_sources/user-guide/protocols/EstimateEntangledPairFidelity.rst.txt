EstimateEntangledPairFidelity
=============================

``entanglement.fidelity``

Estimate lab-frame fidelity and fully entangled fraction from a density matrix.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** no device resources.

Estimates Phi+ lab-frame fidelity, the fully entangled fraction over local unitary frames, and their fidelity gap from a physical two-qubit density matrix without acquiring data or changing hardware.

1 Minimal run
-------------

   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input

     - Meaning
   * - ``twoQubitDensityMatrix``
     - object
     - Output object from ReconstructTwoQubitDensityMatrix, containing its physical rho payload in \|00>, \|01>, \|10>, \|11> order. rho requires numeric 4x4 real arrays; omitted imag means zero, while a supplied imag array must have the same shape. Physical state validation reuses the shared density-matrix validator.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - entanglement.fidelity.\ **estimate**\ .entangledPairFidelity
     - Dimensionless state metrics in [0,1]: labFrameFidelity is the Phi+ overlap in the current laboratory frame; fullyEntangledFraction is the SVD maximum overlap over all maximally entangled two-qubit states, invariant under local unitaries; frameMisalignmentFidelityLoss is their gap (clamped at zero for roundoff), ideally recoverable by local compensation. targetStateDefinition fixes Phi+ = (HH + VV) / sqrt(2). crossCheck contains the independent numerical estimate, bestAttempt/attemptCount, best-frame unitaryA/unitaryB/rhoOptimized as real/imag payloads, numeric SO(3) rotations/unitarity residuals/determinants, and rotationComparison with laboratory/direct/relative angles, Procrustes maps, aligned correlation matrices and Frobenius distances.
   * - entanglement.fidelity.\ **artifact**\ .entangledPairFidelityReport
     - Path to the detailed JSON fidelity report.
   * - entanglement.fidelity.\ **artifact**\ .entangledPairFidelityCompactReport
     - Path to the compact Markdown fidelity summary.
   * - entanglement.fidelity.\ **artifact**\ .densityMatrixPlots
     - Matching PNG/SVG pairs in labFrame and svdFrame, each with real and imaginary 4x4 density-matrix panels, a common signed color scale, and its Phi+ metric in the title.
   * - entanglement.fidelity.\ **artifact**\ .fidelityComparisonPlot
     - Matching PNG/SVG bar chart of laboratory-frame Phi+ fidelity and the independent numerical local-unitary cross-check, on a dimensionless [0,1] axis; no hardware correction is applied.
   * - entanglement.fidelity.\ **artifact**\ .svdDiagnosticsPlot
     - Matching PNG/SVG diagnostic panels of the signed X/Y/Z Pauli correlation matrix, lab/SVD/numerical fidelities on [0,1] axes and singular values; no fidelity delta, agreement verdict or hardware correction.
   * - entanglement.fidelity.\ **artifact**\ .localUnitaryComparisonPlot
     - Matching PNG/SVG panels of numerical/SVD SO(3) rotations for both arms on a common signed [-1,1] scale, direct/relative angles in degrees, matrix distances and numerical residuals.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

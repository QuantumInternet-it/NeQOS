ReadChannelDelays
=================

``timing.alignment``

Read the current input delays of selected Time Tagger channels.

:bdg:`foreground` :bdg:`timeout 2 min`

**Lease:** devices selected by ``timeTaggerDeviceId``.

Read the live temporal input-delay settings of selected Time Tagger channels.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``timeTaggerDeviceId``
     - string length >= 1
     - Identifier of the Time Tagger whose live channel delays are read.
   * - ``channels``
     - integer[] (items >= 1)
     - Physical Time Tagger channels whose current input delays are read.
   * - ``channels[]``
     - integer >= 1
     - Physical Time Tagger channel number.

ReconstructTwoQubitDensityMatrix
================================

``tomography.state``

Reconstruct a physical two-qubit density matrix from complete corrected tomography.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** no device resources.

Reconstructs a physical two-qubit density matrix from a complete background-corrected H/V/D/A/R/L coincidence observation. It preserves the unconstrained linear-inversion estimate as a diagnostic and fits a positive semidefinite trace-one matrix by maximum likelihood. The result is a reconstructed state, not a fidelity metric: downstream protocols may compare it with a target state or derive quality estimates without repeating tomography.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - tomography.state.\ **estimate**\ .twoQubitDensityMatrix
     - Physical maximum-likelihood two-qubit density-matrix estimate with its linear-inversion diagnostic, basis probabilities, Bloch vectors, correlations, optimizer metadata, and source-observation provenance.
   * - tomography.state.\ **status**\ .reconstruction
     - Reconstruction completion state.
   * - tomography.state.\ **artifact**\ .twoQubitDensityMatrixReport
     - Path to the JSON report for the reconstructed density matrix.
   * - tomography.state.\ **artifact**\ .twoQubitDensityMatrixCompactReport
     - Path to the compact Markdown reconstruction summary.
   * - tomography.state.\ **artifact**\ .twoQubitDensityMatrixPlot
     - Path to the SVG visualization of the real and imaginary density-matrix components.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

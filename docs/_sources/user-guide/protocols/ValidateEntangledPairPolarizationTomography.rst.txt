ValidateEntangledPairPolarizationTomography
===========================================

Assesses a complete background-corrected entangled-pair 6x6 coincidence observation before density-matrix reconstruction. It accepts or rejects whole four-outcome basis settings rather than individual projections, because a valid Bell state may have nearly zero complementary outcomes. A rejected assessment remains a completed protocol with its evidence published, so a parent can stop before calculating a misleading fidelity.

Catalog location: ``link.characterization``. This page documents the current exported Reserved contract, not a hardware-test certificate.

ValidateEntangledPairPolarizationTomography
===========================================

``link.characterization``

Assess complete entangled-pair tomography against an explicit acceptance policy.

:bdg:`foreground` :bdg:`timeout 1 min`

**Lease:** no device resources.

Assesses a complete background-corrected entangled-pair 6x6 coincidence observation before density-matrix reconstruction. It accepts or rejects whole four-outcome basis settings rather than individual projections, because a valid Bell state may have nearly zero complementary outcomes. A rejected assessment remains a completed protocol with its evidence published, so a parent can stop before calculating a misleading fidelity.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``entangledPairPolarizationTomography``
     - object
     - Complete output object from MeasureEntangledPairPolarizationCoincidences.
   * - ``qualityGate``
     - object
     - Explicit acceptance policy. It applies to complete four-outcome basis settings, never individual Bell-state projections.
   * - ``qualityGate.minimumCompleteBasisCounts``
     - number >= 0
     - Minimum background-corrected sum of all four outcomes in each of the nine X/Y/Z basis pairs.
   * - ``qualityGate.maximumBasisRateRelativeStandardDeviation``
     - number >= 0
     - Maximum allowed standard-deviation-to-mean ratio across the nine complete basis rates.

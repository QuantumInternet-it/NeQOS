ConfigureQuantumLinkCarrier
===========================

Selects a source output mode and applies the requested total attenuation on every link emitted by that source.

Catalog location: ``link.configuration``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

attenuation
~~~~~~~~~~~

Total attenuation requested on each emitted link. The runtime applies the largest common source contribution possible and uses inline attenuators only for link-specific residual attenuation; every bound inline attenuator declares its supported attenuation grid in network.json.

attenuation.mode
~~~~~~~~~~~~~~~~

preserve changes only output mode; networkConfigured uses the nominal HH or DD targets in network.json; maximumSource sets source attenuation to its maximum and inline attenuators to zero; maximumAvailable sets every available source and inline attenuation component to its maximum; common applies commonDb to every link; perLink applies perLinkDb to every link.

ConfigureQuantumLinkCarrier
===========================

``link.configuration``

Select a source output mode and configure total attenuation on its emitted links.

:bdg:`foreground` :bdg:`timeout 1 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Selects a source output mode and applies the requested total attenuation on every link emitted by that source.

1 Minimal run
-------------

   :header-rows: 1

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``attenuation``
     - {"mode": "preserve"}
     - —
     - Total attenuation requested on each emitted link. The runtime applies the largest common source contribution possible and uses inline attenuators only for link-specific residual attenuation; every bound inline attenuator declares its supported attenuation grid in network.json.
   * - ``attenuation.mode``
     - "preserve"
     - "preserve" \| "networkConfigured" \| "maximumSource" \| "maximumAvailable" \| "common" \| "perLink"
     - preserve changes only output mode; networkConfigured uses the nominal HH or DD targets in network.json; maximumSource sets source attenuation to its maximum and inline attenuators to zero; maximumAvailable sets every available source and inline attenuation component to its maximum; common applies commonDb to every link; perLink applies perLinkDb to every link. Required when the containing object or array item is supplied.
   * - ``attenuation.commonDb``
     - not declared
     - >= 0
     - Total attenuation requested on every emitted link when mode is common.
   * - ``attenuation.perLinkDb``
     - not declared
     - —
     - Total attenuation requested for each source link when mode is perLink; it must contain every source link exactly once.
   * - ``settleSec``
     - 0.2
     - >= 0
     - Delay after applying the carrier configuration, in seconds.

CompensateLinkPolarizationFromSeparableHDProbes
===============================================

``link.polarizationCompensation``

Estimate and install one link compensation table from separable H/D probes.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Compensates one analyzer-equipped link from factory-state H/D singles tomography and a measured background, installs the estimated table without post-installation verification, and restores the exact pre-campaign source traffic, source attenuations and inline-attenuator settings; PA1000/PA2000 optical configuration is supported, while MPC320 requires driver support for readOpticalConfiguration. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``linkId``
     - string length >= 1
     - Analyzer-equipped emitted link to compensate.
   * - ``deviceId``
     - string length >= 1
     - Source device that emits linkId.
   * - ``resourceDeviceIds``
     - string[] (items >= 3)
     - Exact lease union: emitting source, every inline attenuator that its carrier configuration may write, the resolved TimeTagger, and the resolved polarization analyzer.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One unique device identifier in the link-compensation lease union.
   * - ``probeAttenuation``
     - object
     - Total attenuation request used for both H and D probe traffic, in the ConfigureQuantumLinkCarrier attenuation form. Use mode perLink with every emitted source link when their required totals differ; the carrier distributes each total between the source and its inline attenuator.
   * - ``probeAttenuation.mode``
     - string "common" \| "perLink"
     - Carrier attenuation mode. This campaign normally uses perLink or common; networkConfigured is reserved for its final restore.
   * - ``latchGuard``
     - object
     - Explicit finite-window latch policy propagated to background and tomography acquisitions. required rejects invalid windows and retries only after detector recovery; disabled deliberately acquires without latch protection.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether per-window detector-latch validation is disabled or required.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of an invalid window after a recovered latch.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``probeAttenuation.commonDb``
     - not declared
     - >= 0
     - Total attenuation on every source-emitted link when mode is common.
   * - ``probeAttenuation.perLinkDb``
     - not declared
     - —
     - Total attenuation by source-emitted link when mode is perLink. The carrier requires every emitted source link exactly once.
   * - ``measurementDurationSec``
     - 2
     - —
     - Finite duration of each singles acquisition window, in seconds.
   * - ``settleSec``
     - 1
     - >= 0
     - Delay after carrier or analyzer-state changes and before the following finite measurement window, in seconds. The default preserves a one-second physical settling interval for analyzer rotations.
   * - ``minTotalCounts``
     - 1
     - >= 0
     - Minimum total background-corrected logical tomography counts required independently for the H and D source probes.
   * - ``persist``
     - true
     - —
     - Persist the installed compensation table on the analyzer DeviceOS host by default; set false for a nonpersistent installation. Persistence does not imply a physical acceptance gate.

MeasureEntangledPairPolarizationCoincidences
============================================

``link.characterization``

Acquire guarded two-arm polarization tomography as a logical 6x6 coincidence matrix.

:bdg:`foreground` :bdg:`timeout 120 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Measures a logical 6x6 coincidence matrix across two entangled-pair analyzer arms. Every physical acquisition uses the standard required detector-latch guard, so a recovered latch retries only its affected window while preserving previously accepted projections.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``linkPairIds``
     - string[2]
     - Exactly two distinct entangled-pair link identifiers, defining row and column order in the returned matrix. They must resolve to two distinct analyzer channels, which may belong to one PA2000/MPC320 device or two separate devices.
   * - ``linkPairIds[]``
     - string length >= 1
     - One entangled-pair link identifier resolved from network.json.
   * - ``polarizationAnalyzerDeviceIds``
     - string[] (items >= 1)
     - Unique analyzer device identifiers resolved from the selected link arms and leased for the whole matrix. Supports two PA1000 or two MPC320 devices, or one two-channel PA2000/MPC320; each resolved channel may use a polarizer or PBS topology declared in network.json.
   * - ``polarizationAnalyzerDeviceIds[]``
     - string length >= 1
     - One polarization-analyzer device identifier.
   * - ``resourceDeviceIds``
     - string[] (items >= 3)
     - Exact lease union of the resolved TimeTagger, every analyzer device, and every detector-health device selected by the TimeTagger healthGuards mappings.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One device retained for the complete tomography attempt.
   * - ``latchGuard``
     - object
     - Required detector-latch policy for every physical child coincidence window. The TimeTagger healthGuards topology selects the health devices and channel mappings; only the affected window is retried after recovery.
   * - ``latchGuard.mode``
     - string "required"
     - This finite tomography always requires detector-latch protection.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of one recovered latch-invalid physical acquisition window.

   * - link.characterization.\ **observation**\ .entangledPairPolarizationCoincidences

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 10
     - —
     - Finite integration duration for each physical analyzer configuration, in seconds. network.json topology selects 36 configurations for two polarizers, 18 for PBS/polarizer, or 9 for two PBS analyzers.
   * - ``settleSec``
     - 1
     - >= 0
     - Non-blocking delay after each analyzer-state change and before its finite measurement window, in seconds. The default allows the polarization analyzers to settle physically.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence window for every projection, in picoseconds.
   * - ``useCompensatedTomoStates``
     - false
     - —
     - Whether analyzer states are applied from installed or loaded compensation tables; false uses factory states and never requires a compensation table.
   * - ``backgroundCountRateHz``
     - 0
     - >= 0
     - Coincidence background rate subtracted from each finite projection before the corrected matrix is reported.
   * - ``clear``
     - true
     - —
     - Must be true so an invalid latch-guarded child window can be retried as a fresh integration.
   * - ``dwdmChannelByLink``
     - {}
     - —
     - Optional per-link DWDM channel overrides for analyzer wavelength preparation.
   * - ``defaultDwdmChannel``
     - null
     - >= 1
     - Optional fallback DWDM channel when a selected link omits one in network.json.
   * - ``useCompensatedTomoStatesByLink``
     - {}
     - —
     - Optional exact map of both linkIds to boolean table policies. A nonempty map overrides useCompensatedTomoStates, allowing a factory reference and compensated target without changing either policy implicitly.

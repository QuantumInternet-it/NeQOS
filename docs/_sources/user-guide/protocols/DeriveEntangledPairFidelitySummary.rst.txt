DeriveEntangledPairFidelitySummary
==================================

Derives a unified fidelity and detected-throughput summary, verifies matrix-to-metric consistency, and renders laboratory, SVD and numerical cross-check density matrices without reacquiring data or repeating optimization.

Catalog location: ``entanglement.fidelity``. This page documents the current exported Reserved contract, not a hardware-test certificate.

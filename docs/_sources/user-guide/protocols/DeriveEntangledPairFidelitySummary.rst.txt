DeriveEntangledPairFidelitySummary
==================================

``entanglement.fidelity``

Combine existing fidelity and throughput results into a verified summary.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** no device resources.

Derives a unified fidelity and detected-throughput summary, verifies matrix-to-metric consistency, and renders laboratory, SVD and numerical cross-check density matrices without reacquiring data or repeating optimization.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - entanglement.fidelity.\ **estimate**\ .entangledPairFidelitySummary
     - Aggregate of labFrameFidelity, fullyEntangledFraction, frameMisalignmentFidelityLoss, numerical crossCheck (no delta), detected hashing throughput, three frame matrices and input provenance.
   * - entanglement.fidelity.\ **artifact**\ .entangledPairFidelitySummaryReport
     - Detailed aggregate JSON report.
   * - entanglement.fidelity.\ **artifact**\ .entangledPairFidelitySummaryCompactReport
     - Markdown summary with links to the three density-matrix figures.
   * - entanglement.fidelity.\ **artifact**\ .entangledPairFidelitySummaryPlots
     - Three paired PNG/SVG signed-3D real/imaginary matrix plots on common scales with numeric labels and dashed ideal Phi+ references.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

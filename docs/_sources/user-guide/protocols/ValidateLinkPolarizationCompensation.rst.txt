ValidateLinkPolarizationCompensation
====================================

``link.polarizationCompensation``

Assess installed link compensation from complete separable H/D tomography.

:bdg:`foreground` :bdg:`timeout 30 s`

**Lease:** no device resources.

Validates an already applied link-polarization compensation from complete H and D separable source-probe H/V/D/A/R/L tomography counts. It derives measured Stokes vectors plus H, D, and average polarization-direction agreement; it does not calculate state fidelity, acquire data, read a device, write a device, or install a compensation table.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.polarizationCompensation.\ **observation**\ .separableHDValidation
     - Normalized H/D validation counts, measured Stokes vectors, and S0 values after the caller's compensation installation.
   * - link.polarizationCompensation.\ **estimate**\ .separableHDDirectionAgreement
     - Derived H, D, and average normalized-Stokes direction agreements for the supplied post-compensation H/D validation observations; this is not a state-fidelity metric.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

MeasureLinkBackgroundSingles
============================

``link.characterization``

Measure link singles background while preserving and restoring the carrier state.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Measures the finite singles background on one or more semantic quantum links. The protocol snapshots both live EPS attenuation paths, output mode, and every bound inline attenuator of each resolved source. Any traffic-mode change is first protected at declared source/attenuator maxima; it then parks each source at maximum entangled attenuation, composes MeasureLinkSingles, and restores the exact live state. The source and TimeTagger leases remain owned for the complete park/acquire/restore bracket, including failure cleanup. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``targetLinkIds``
     - string[] (items >= 1)
     - Quantum links whose H TimeTagger sink channels are measured after their resolved sources are parked.
   * - ``targetLinkIds[]``
     - string length >= 1
     - One target quantum-link identifier resolved from network.json.
   * - ``resourceDeviceIds``
     - string[] (items >= 2)
     - Exactly the sources resolved from targetLinkIds, every inline attenuator on their source-emitted links, and their one TimeTagger; this reserves the complete safe park/measurement/restore bracket.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One resolved source, its bound inline attenuator, or TimeTagger device identifier.
   * - ``latchGuard``
     - object
     - Explicit finite-window latch policy propagated to background and tomography acquisitions. required rejects invalid windows and retries only after detector recovery; disabled deliberately acquires without latch protection.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether per-window detector-latch validation is disabled or required.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of an invalid window after a recovered latch.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.characterization.\ **plan**\ .background
     - Resolved links, sources, TimeTagger, resource bracket, and finite acquisition settings.
   * - link.characterization.\ **applied**\ .sourceParking
     - Source parking values applied before the background acquisition and subsequently restored.
   * - link.characterization.\ **observation**\ .background
     - Finite singles background observation imported from MeasureLinkSingles with source-parking provenance.
   * - link.characterization.\ **status**\ .restoration
     - Verified source-state restoration status and read-backs after the background observation.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 1
     - —
     - Finite integration duration of the background singles acquisition, in seconds.
   * - ``settleSec``
     - 0.2
     - >= 0
     - Delay after parking the source carriers and before the finite acquisition, in seconds.
   * - ``restoreSettleSec``
     - 0.2
     - >= 0
     - Delay after verified carrier restoration before the protocol completes, in seconds.
   * - ``clear``
     - true
     - —
     - Whether the finite singles acquisition clears its stable count-rate measurements first.

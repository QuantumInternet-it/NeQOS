LoadPolarizationAnalyzerCompensation
====================================

``device.calibrationStore``

Load stored analyzer compensation tables and optionally apply a state.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``polarizationAnalyzerDeviceId``.

Loads persisted compensated tomography states for selected or every stored channel on one PA X000 or MPC320 DeviceOS host and can apply one loaded state.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``polarizationAnalyzerChannels``
     - null
     - items >= 1
     - Optional non-empty list of analyzer channels to load. When omitted, loads every channel persisted on this DeviceOS host; MPC320 supports only channel 1.
   * - ``polarizationAnalyzerChannels[]``
     - not declared
     - >= 1
     - One analyzer channel to load. Required when the containing object or array item is supplied.
   * - ``applyTomographyState``
     - null
     - —
     - Optional compensated H/V/D/A/R/L state to apply immediately after loading.

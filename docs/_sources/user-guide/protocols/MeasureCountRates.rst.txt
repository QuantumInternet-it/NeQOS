MeasureCountRates
=================

``acquisition.countrate``

Acquire one finite window of channel counts and count rates.

:bdg:`foreground` :bdg:`timeout 2 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Acquire one finite count-rate observation for the requested device channels and return normalized counts and rates by measurement reference.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``deviceId``
     - string length >= 1
     - Device that acquires the requested count-rate measurements.
   * - ``resourceDeviceIds``
     - string[] (items >= 1)
     - Exact lease union: only the TimeTagger when latchGuard is disabled, or that TimeTagger plus every network-resolved detector-health guard when it is required.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One device needed by this finite acquisition.
   * - ``channelRefs``
     - integer[] (items >= 1)
     - Unique physical or logical channel references measured in one acquisition window.
   * - ``channelRefs[]``
     - integer >= 0
     - One channel reference accepted by the acquisition device.
   * - ``latchGuard``
     - object
     - Explicit finite-window detector-latch policy; disabled permits an unguarded observation, while required validates network-declared detector-health guards and retries only the invalid window.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether detector-latch validation is disabled or required for this observation.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries after a recovered detector latch; use zero to reject the first invalid window.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - acquisition.countrate.\ **observation**\ .window
     - Normalized context and raw device response for the completed acquisition window.
   * - acquisition.countrate.\ **observation**\ .countsByMeasurement
     - Normalized total counts indexed by measurement reference.
   * - acquisition.countrate.\ **observation**\ .countRatesHzByMeasurement
     - Observed count rates in hertz indexed by measurement reference.
   * - acquisition.countrate.\ **status**\ .latchGuard
     - Explicit latch-guard policy, health samples, accepted-window attempt, discarded-window count, and any terminal guard failure.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

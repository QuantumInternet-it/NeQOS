EstimateLinkPolarizationCompensationFromHDProbes
================================================

Estimates per-link polarization compensation from source-prepared or entangled H/D H/D tomography counts and externally supplied calibrated analyzer axes, without acquiring data or touching hardware.

Catalog location: ``link.polarizationCompensation``. This page documents the current exported Reserved contract, not a hardware-test certificate.

linkTomographyInputs
~~~~~~~~~~~~~~~~~~~~

Non-empty object indexed by target link ID. Each entry requires observationKind (singles or coincidences), explicit probeTraffic (classical or entangled), required without a default, countsByProbeState with complete H and D H/V/D/A/R/L counts, and calibrated finite 3x3 waveplateAxes supplied by the caller (normally from ReadPolarizationAnalyzerOpticalConfiguration). Entangled entries require coincidences, a different referenceLinkId, and explicit boolean referenceUseCompensatedTomoStates; classical entries must omit those reference fields. Counts must already have the chosen background treatment. The solver computes retardances for calibrated HDH-compatible variable retarders; it neither reads optical configuration nor applies a correction.

minTotalCounts
~~~~~~~~~~~~~~

Minimum sum of the six logical tomography counts required independently for each H or D probe, regardless of preparation.

   * - Export key

   * - ``link.polarizationCompensation.estimate.hdProbeCompensationByLink``
     - estimate / object
     - Independent per-link H/D Stokes/Mueller compensation estimates, including explicit source/entangled H/D provenance, neutral countsByProbeState and Stokes fields, complete H/V/D/A/R/L retardances, and polarization-direction agreement (not state fidelity). Under the unitary Phi+ model, entangled correction is relative to the reference analyzer's selected basis and cannot separate target-link rotation from source-side rotation or a non-Phi+ state. No estimate is applied to hardware.

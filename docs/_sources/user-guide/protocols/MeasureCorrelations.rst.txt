MeasureCorrelations
===================

Acquire finite raw correlation histograms for the requested TimeTagger channel pairs without deriving physical estimates.

Catalog location: ``acquisition.correlation``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

Outputs and evidence
--------------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Role / type
     - Meaning
   * - ``acquisition.correlation.observation.window``
     - observation / object
     - Verified context and raw device response for the completed shared correlation window.
   * - ``acquisition.correlation.plan.definitionsByCorrelation``
     - plan / object
     - Resolved stable histogram definitions indexed by correlation identifier.
   * - ``acquisition.correlation.observation.histogramsByCorrelation``
     - observation / object
     - Raw delay and coincidence histogram arrays indexed by correlation identifier.
   * - ``acquisition.correlation.status.latchGuard``
     - status / object
     - Explicit latch-guard policy, health samples, accepted-window attempt, discarded-window count, and any terminal guard failure.

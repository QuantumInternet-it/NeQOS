MeasureCorrelations
===================

``acquisition.correlation``

Acquire correlation histograms for selected Time Tagger channel pairs.

:bdg:`foreground` :bdg:`timeout 2 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Acquire finite raw correlation histograms for the requested TimeTagger channel pairs without deriving physical estimates.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``deviceId``
     - string length >= 1
     - TimeTagger device that acquires the requested correlation histograms.
   * - ``resourceDeviceIds``
     - string[] (items >= 1)
     - Exact lease union: only the TimeTagger when latchGuard is disabled, or that TimeTagger plus every network-resolved detector-health guard when it is required.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One device needed by this finite acquisition.
   * - ``correlations``
     - object[] (items >= 1)
     - Unique correlation-histogram definitions acquired together in one finite window.
   * - ``correlations[]``
     - object
     - One named channel-pair histogram definition.
   * - ``correlations[].correlationId``
     - string length >= 1
     - Caller-stable identifier used as the output-map key.
   * - ``correlations[].channelRefA``
     - integer >= 0
     - First physical TimeTagger channel reference.
   * - ``correlations[].channelRefB``
     - integer >= 0
     - Second physical TimeTagger channel reference.
   * - ``correlations[].binWidthPs``
     - integer >= 1
     - Histogram bin width in picoseconds.
   * - ``correlations[].binCount``
     - integer >= 1
     - Number of histogram bins.
   * - ``latchGuard``
     - object
     - Explicit finite-window detector-latch policy; disabled permits an unguarded observation, while required validates network-declared detector-health guards and retries only the invalid window.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether detector-latch validation is disabled or required for this observation.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries after a recovered detector latch; use zero to reject the first invalid window.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - acquisition.correlation.\ **observation**\ .window
     - Verified context and raw device response for the completed shared correlation window.
   * - acquisition.correlation.\ **plan**\ .definitionsByCorrelation
     - Resolved stable histogram definitions indexed by correlation identifier.
   * - acquisition.correlation.\ **observation**\ .histogramsByCorrelation
     - Raw delay and coincidence histogram arrays indexed by correlation identifier.
   * - acquisition.correlation.\ **status**\ .latchGuard
     - Explicit latch-guard policy, health samples, accepted-window attempt, discarded-window count, and any terminal guard failure.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

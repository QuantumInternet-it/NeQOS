AlignChannels
=============

Measure correlations from a reference channel to target channels, estimate their relative timing offsets, and optionally apply the derived input delays.

Catalog location: ``timing.alignment``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

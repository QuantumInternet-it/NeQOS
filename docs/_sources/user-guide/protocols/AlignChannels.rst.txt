AlignChannels
=============

``timing.alignment``

Measure relative channel timing offsets and optionally apply the derived input delays.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** no device resources.

Measure correlations from a reference channel to target channels, estimate their relative timing offsets, and optionally apply the derived input delays.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - timing.alignment.\ **observation**\ .channelAlignment
     - Measured correlations, selected peak estimates, and per-channel alignment outcomes.
   * - timing.alignment.\ **observation**\ .correlations
     - Correlation records indexed by reference-to-target measurement key.
   * - timing.alignment.\ **applied**\ .channelDelays
     - Initial live baseline plus planned, read-back, and applied Time Tagger input delays.
   * - timing.alignment.\ **artifact**\ .histogramPngByCorrelation
     - NodeEngine-local PNG diagnostic path for each coarse, fine, or single alignment histogram.
   * - timing.alignment.\ **artifact**\ .histogramSvgByCorrelation

   * - ``acquisition.fine.binCount``
     - null
     - >= 1
     - Histogram bin count; if null, acquisition.pumpFrequencyMHz is required to derive it.
   * - ``acquisition.pumpFrequencyMHz``
     - null
     - >= 0
     - Pump frequency used to derive any omitted bin counts; required whenever the selected pass has binCount null.
   * - ``delayCorrection``
     - {"apply": true, "basePs": null, "settleSec": 0.2, "sign": 1}
     - —
     - Policy for applying estimated input delays after reading the live Time Tagger baseline.
   * - ``delayCorrection.apply``

     - —
     - Apply estimated offsets as Time Tagger input delays. Required when the containing object or array item is supplied.
   * - ``delayCorrection.sign``
     - 1
     - —
     - Sign applied to each estimated offset. Required when the containing object or array item is supplied.
   * - ``delayCorrection.basePs``
     - null
     - —
     - Optional common input-delay baseline in picoseconds.
   * - ``delayCorrection.settleSec``
     - 0.2
     - >= 0
     - Delay after applying a correction round, in seconds. Required when the containing object or array item is supplied.
   * - ``peakSelection``
     - structured value (see Technical details)
     - —

   * - ``peakSelection.mode``
     - "dominant"
     - "dominant" \| "rank" \| "index" \| "nth" \| "closest" \| "nearest"
     - Rule used to select a correlation peak. Required when the containing object or array item is supplied.
   * - ``peakSelection.rank``
     - 1
     - >= 1
     - Rank used by ranked selection modes. Required only for rank/index/nth selection; unused for other modes.
   * - ``peakSelection.targetDelayPs``
     - null
     - —
     - Target delay used by nearest-peak selection. Required for closest/nearest selection; there is no dominant-peak fallback.
   * - ``peakSelection.rejectCenterPs``

   * - ``peakSelection.rejectHalfWidthPs``
     - null
     - —

   * - ``peakSelection.gaussianFitMaxHalfWidthPs``
     - null
     - —
     - Optional maximum half-width for local Gaussian fitting.
   * - ``peakSelection.diagnosticMaxPeaks``
     - 20
     - >= 0
     - Maximum locally selected diagnostic peaks to retain; zero retains all after minSeparationPs filtering. Required when the containing object or array item is supplied.
   * - ``peakSelection.minSeparationPs``
     - 100
     - >= 0
     - Minimum separation between diagnostic peaks in picoseconds. Required when the containing object or array item is supplied.
   * - ``peakSelection.minCoincidences``
     - 1
     - >= 0
     - Minimum coincidences required for a selected peak. Required when the containing object or array item is supplied.

MeasureLinkCoincidences
=======================

``link.characterization``

Measure coincidence counts and rates between resolved reference and target links.

:bdg:`foreground` :bdg:`timeout 3 min`

**Lease:** no device resources.

Measures finite reference-target coincidence counts and rates for resolved quantum links and returns their acquisition provenance.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``referenceLinkId``
     - string length >= 1
     - Quantum-link identifier whose TimeTagger sink channel is paired with every target link.
   * - ``targetLinkIds``
     - string[] (items >= 1)
     - Unique target quantum-link identifiers paired with the reference link in one acquisition window.
   * - ``targetLinkIds[]``
     - string length >= 1
     - One target quantum-link identifier resolved from network.json.

.. code-block:: json

   {
     "schemaVersion": "0.4",
     "metaProtocolLibrary": {
       "libraryId": "neqos-protected"
     },
     "steps": [
       {
         "protocolId": "MeasureLinkCoincidences",
         "sharedParams": {
           "referenceLinkId": "ExampleReferenceLinkId",
           "targetLinkIds": [
             "ExampleTargetLinkId"
           ]
         }
       }
     ]
   }

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.characterization.\ **observation**\ .coincidences
     - Reference-target coincidence counts and available rates by target link, with resolved channels and acquisition provenance.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 1
     - —
     - Finite integration duration for the shared coincidence observation window, in seconds.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND-logical coincidence window, in picoseconds.
   * - ``clear``
     - true
     - —
     - Whether the selected stable coincidence measurements are cleared before acquisition.

ApplyChannelDelays
==================

``timing.alignment``

Apply an explicit input-delay map to Time Tagger channels.

:bdg:`foreground` :bdg:`declared timeout 2 min`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``timeTaggerDeviceId``.

Apply an explicit temporal-delay map to the input channels of a Time Tagger.

-------------

   * - Input
     - Type

   * - ``timeTaggerDeviceId``
     - string length >= 1
     - Identifier of the Time Tagger whose channel delays are updated.
   * - ``channelDelaysPs``
     - object
     - Explicit map from physical channel number to temporal input delay in picoseconds.

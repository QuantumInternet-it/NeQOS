CompensateSourcePolarizationFromEntangledPairProbes
===================================================

``link.polarizationCompensation``

Compensate relative link polarization using entangled H/D coincidence probes.

:bdg:`foreground` :bdg:`timeout 120 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Compensates the relative polarization mismatch between the two links emitted by one entangled-photon source, using entangled H/D H/D coincidence probes under the Phi+ convention and applying the resulting correction to only the selected target analyzer. It optionally installs and persists that analyzer table, then restores the original carrier state. The method attributes all observed reference-frame mismatch to the target and cannot distinguish link rotation, local source rotation or a departure from Phi+. Before conditional H/D scans it always composes MeasureLinkBackgroundCoincidences, parking the pair source and restoring its exact active setup. All physical detector pairs used by the scans are acquired together for measurementDurationSec with the same coincidence window and latch policy. External background input is not accepted; subtractBackground controls correction, not acquisition.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``referenceLinkId``
     - string length >= 1
     - Reference analyzer link that heralds H/D probes under the Phi+ correlation convention.
   * - ``compensationTargetLinkId``
     - string length >= 1
     - Other emitted link whose single analyzer receives the calculated correction.
   * - ``resourceDeviceIds``
     - string[] (items >= 1)
     - Exact union of both analyzers, measured TimeTagger, explicitly required detector guards, sources and all inline attenuators potentially changed by sourceSetup.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One leased device.
   * - ``referenceUseCompensatedTomoStates``
     - boolean
     - Explicit choice of factory or installed/loaded compensated reference states; true fails if the reference table is unavailable.
   * - ``latchGuard``
     - object
     - Explicit finite-window protection; no implicit detector guard and no matrix-level retry.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Guard policy.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Immediate retries of a recovered latch-invalid window.
   * - ``sourceSetup``
     - object
     - Explicit source and inline-attenuator setup. An empty object preserves an already ENTANGLED source; no second source is inferred or parked. Source traffic/attenuation and inline ATT values are snapshotted and restored normally and on terminal failure. Omit unused sources/attenuators members or supply arrays (not null). Supplied attenuation values must be numeric/non-null and within network limits; absent source attenuation fields mean no change.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``targetUseCompensatedTomoStates``
     - false
     - —
     - Target acquisition table; false uses factory states, true requires an installed/loaded table.
   * - ``referenceResetCompensatedTomoStates``
     - true
     - —
     - After target installation succeeds, replace only the reference compensated table with its six factory-state read-backs; default true. Requires referenceUseCompensatedTomoStates=false. Uses the same persist flag; estimate-only runs do not reset. The reset returns the reference to H by default, or to its last reference projection when setFinalHAfterApply=false.
   * - ``measurementEnabled``
     - true
     - —
     - False publishes a SKIPPED report without communicating with hardware.
   * - ``measurementDurationSec``
     - 2
     - —
     - Equal finite duration of every conditional acquisition window in seconds.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence interval in picoseconds.
   * - ``settleSec``
     - 1
     - >= 0
     - Physical settling interval after analyzer or carrier changes.
   * - ``clear``
     - true
     - —
     - Fresh windows; false is invalid with a required latch guard.
   * - ``pbsReadout``
     - "simultaneous"
     - "simultaneous" \| "symmetrized"
     - Target PBS readout: simultaneous acquires both ports at H/D/R; symmetrized acquires all six settings. One branch averages the two same-projection readings. A multibranch topology preserves the legacy sum of selected components, even if just one branch is selected.
   * - ``targetBranchMode``
     - "both"
     - "both" \| "branch1" \| "branch2" \| "branch1-positive" \| "branch1-negative" \| "branch2-positive" \| "branch2-negative"
     - Fit selected target branch(es); positive/negative mean the lower/higher numbered physical detector within a branch, not a logical H/V state. Network outputPort provides logical orientation. Unselected measured components remain diagnostic evidence.
   * - ``referenceDetectorChannel``
     - null
     - >= 0
     - Optional selected reference sink channel, validated against referenceLinkId.
   * - ``referenceProjectionSetMode``
     - "compact2x6"
     - "compact2x6"
     - H,D reference probes against the six logical target projections. Only compact2x6 is supported; extended pre-installation acquisition is retired.
   * - ``subtractBackground``
     - false
     - —
     - Subtract the internally acquired detector-pair background from each scan component using integration-duration scaling and zero clipping. False still measures and retains the background, but leaves scan counts uncorrected.
   * - ``sourceSetup.sources``
     - not declared
     - —
     - Explicit source traffic/attenuation requests.
   * - ``sourceSetup.sources[]``
     - not declared
     - —
     - One source request. Required when the containing object or array item is supplied.
   * - ``sourceSetup.sources[].deviceId``
     - not declared
     - length >= 1
     - Source device. Required when the containing object or array item is supplied.
   * - ``sourceSetup.sources[].outputMode``
     - not declared
     - "HH" \| "DD" \| "ENTANGLED"
     - Carrier traffic.
   * - ``sourceSetup.sources[].entangledOutputAttenuationDb``
     - not declared
     - >= 0
     - Entangled source attenuation, within network limits.
   * - ``sourceSetup.sources[].classicOutputAttenuationDb``
     - not declared
     - >= 0
     - Classic source attenuation, within network limits.
   * - ``sourceSetup.attenuators``
     - not declared
     - —
     - Explicit inline attenuators on configured source links.
   * - ``sourceSetup.attenuators[]``
     - not declared
     - —
     - One attenuation request. Required when the containing object or array item is supplied.
   * - ``sourceSetup.attenuators[].deviceId``
     - not declared
     - length >= 1
     - Attenuator device. Required when the containing object or array item is supplied.
   * - ``sourceSetup.attenuators[].attenuationDb``
     - not declared
     - >= 0
     - Attenuation within network limits. Required when the containing object or array item is supplied.
   * - ``applyCompensation``
     - false
     - —
     - Install only the target compensation table; false leaves both tables unchanged.
   * - ``persist``
     - true
     - —
     - Persist an installed estimate on the DeviceOS host by default; set false for a nonpersistent installation. This flag does not enable installation or imply a physical acceptance gate.
   * - ``setFinalHAfterApply``
     - true
     - —
     - After successful target installation, leave both target and reference physically in H. The target uses its installed table; the reference uses the reset factory-equivalent table, or its selected existing policy when reset is disabled. False preserves the prior last-reference-projection behavior; estimate-only runs are unchanged.
   * - ``hardCheckStokesAngle``
     - false
     - —
     - Preserved optional H/D direction-angle acceptance check, disabled by default.
   * - ``stokesAngleTargetDeg``
     - 90
     - >= 0; <= 90
     - Expected acute angle between H/D Stokes directions in degrees.
   * - ``stokesAngleToleranceDeg``
     - 15
     - >= 0
     - Optional direction-angle tolerance in degrees.
   * - ``minTotalCounts``
     - 1
     - >= 0
     - Minimum summed counts for each H/D probe passed to the existing pure estimator.

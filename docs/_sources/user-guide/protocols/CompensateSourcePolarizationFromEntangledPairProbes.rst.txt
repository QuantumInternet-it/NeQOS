CompensateSourcePolarizationFromEntangledPairProbes
===================================================

Compensates the relative polarization mismatch between the two links emitted by one entangled-photon source, using entangled H/D H/D coincidence probes under the Phi+ convention and applying the resulting correction to only the selected target analyzer. It optionally installs and persists that analyzer table, then restores the original carrier state. The method attributes all observed reference-frame mismatch to the target and cannot distinguish link rotation, local source rotation or a departure from Phi+. Before conditional H/D scans it always composes MeasureLinkBackgroundCoincidences, parking the pair source and restoring its exact active setup. All physical detector pairs used by the scans are acquired together for measurementDurationSec with the same coincidence window and latch policy. External background input is not accepted; subtractBackground controls correction, not acquisition.

Catalog location: ``link.polarizationCompensation``. This page documents the current exported Reserved contract, not a hardware-test certificate.

MeasureLinkPolarizationCoincidences
===================================

``link.characterization``

Measure link coincidence tomography across logical analyzer states.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** devices selected by ``polarizationAnalyzerDeviceIds``, ``resourceDeviceIds``.

Measures finite reference-target coincidence counts and rates across logical analyzer states for one or more analyzer-equipped target links. network.json declares each channel as polarizer or PBS: complementary PBS outputs are acquired together, reducing physical settings without changing the reported logical states. An optional symmetrized PBS readout preserves opposite-port component evidence and the declared single-branch average or multibranch sum.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``tomographyStates``
     - ["H", "V", "D", "A", "R", "L"]
     - items >= 1
     - Logical H/V/D/A/R/L projections to report. A PBS acquires complementary pairs from one physical H/D/R setting; a polarizer requires one setting per requested logical projection.
   * - ``tomographyStates[]``
     - not declared
     - length >= 1
     - One analyzer state accepted by the polarization analyzer. Required when the containing object or array item is supplied.
   * - ``measurementDurationSec``
     - 3
     - —
     - Finite coincidence acquisition duration for each analyzer state, in seconds.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence window used for every analyzer state, in picoseconds.
   * - ``settleSec``
     - 1
     - >= 0
     - Non-blocking delay after each analyzer-state change and before its finite measurement window, in seconds. The default allows the polarization analyzer to settle physically.
   * - ``clear``
     - true
     - —
     - Whether every finite acquisition window starts from cleared measurements.
   * - ``useCompensatedTomoStates``
     - false
     - —
     - Whether named analyzer states are resolved from an installed or loaded compensation table instead of the factory tomography table.
   * - ``dwdmChannelByLink``
     - {}
     - —
     - Optional per-target DWDM channel overrides for analyzer wavelength configuration.
   * - ``defaultDwdmChannel``
     - null
     - >= 1
     - Optional fallback DWDM channel when a target link does not declare one in network.json.
   * - ``finalTomographyState``
     - null
     - length >= 1
     - Optional state applied to every target analyzer after the scan, including best-effort terminal cleanup after a failed or aborted scan.
   * - ``pbsReadout``
     - "simultaneous"
     - "simultaneous" \| "symmetrized"
     - PBS target readout: simultaneous reads complementary ports together in three settings; symmetrized uses six settings. One branch averages same-projection opposite-port readings; a multibranch topology preserves the sum of selected components, even when only one branch is selected.
   * - ``targetBranchMode``
     - "both"
     - "both" \| "branch1" \| "branch2" \| "branch1-positive" \| "branch1-negative" \| "branch2-positive" \| "branch2-negative"
     - Selected target branch(es). positive/negative select respectively the lower/higher numbered physical detector in that branch; logical orientation still follows network H/V port bindings. All measured components remain available.
   * - ``referenceDetectorChannel``
     - null
     - >= 0
     - Optional selected reference detector; must be a sink of referenceLinkId. Other reference outputs are preserved when scanning a single target output.
   * - ``resourceDeviceIds``
     - []
     - —
     - Acquisition lease union: TimeTagger and explicitly required health guards. An empty list preserves the existing unguarded child-owned TimeTagger behavior.
   * - ``resourceDeviceIds[]``
     - not declared
     - length >= 1
     - One acquired device. Required when the containing object or array item is supplied.
   * - ``latchGuard``
     - {"maxWindowRetries": 0, "mode": "disabled"}
     - —
     - Explicit finite-window policy. The default preserves the existing unguarded scan; required needs network healthGuards and their exact acquisition lease union.
   * - ``latchGuard.mode``
     - "disabled"
     - "disabled" \| "required"
     - Window policy. Required when the containing object or array item is supplied.
   * - ``latchGuard.maxWindowRetries``
     - 0
     - >= 0
     - Immediate window retries. Required when the containing object or array item is supplied.
   * - ``subtractBackground``
     - false
     - —
     - Subtract a duration-scaled detector-pair background before combining physical components, clipping each component at zero.
   * - ``backgroundObservation``
     - {}
     - —
     - Background countsByPair keyed referenceChannel&targetChannel and positive measurementDurationSec; required when subtractBackground is true.
   * - ``backgroundObservation.countsByPair``
     - not declared
     - —
     - Non-negative detector-pair counts.
   * - ``backgroundObservation.measurementDurationSec``
     - not declared
     - —
     - Background integration seconds.

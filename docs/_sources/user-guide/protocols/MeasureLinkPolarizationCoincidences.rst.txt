MeasureLinkPolarizationCoincidences
===================================

Measures finite reference-target coincidence counts and rates across logical analyzer states for one or more analyzer-equipped target links. network.json declares each channel as polarizer or PBS: complementary PBS outputs are acquired together, reducing physical settings without changing the reported logical states. An optional symmetrized PBS readout preserves opposite-port component evidence and the declared single-branch average or multibranch sum.

Catalog location: ``link.characterization``. This page documents the current exported Reserved contract, not a hardware-test certificate.

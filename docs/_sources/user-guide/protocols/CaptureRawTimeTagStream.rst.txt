CaptureRawTimeTagStream
=======================

``acquisition.rawStream``

Capture, close and transfer a raw time-tag stream for a quantum link.

:bdg:`foreground` :bdg:`timeout 1441 min`

**Lease:** devices selected by ``timeTaggerDeviceId``.

Resolve a link's TimeTagger channels from the active network, then declaratively start, hold, stop, and transfer one closed raw stream within the same lease-root instance.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``operation``
     - "record"
     - "record" \| "stream"
     - Use stream for the canonical lifecycle-safe semantic capture. record is a compatibility alias and may be retired in a future major release; both values execute the declared start, hold, stop, and transfer lifecycle within this lease-root instance.
   * - ``detectorPorts``
     - []
     - —
     - Optional subset of named sink ports; an empty list records every sink channel of the link.
   * - ``detectorPorts[]``
     - not declared
     - length >= 1
     - One link sink-port label such as H or V. Required when the containing object or array item is supplied.
   * - ``durationSec``
     - 30
     - —
     - Declared raw-stream hold duration in seconds.
   * - ``recordingSubdirectory``
     - null
     - length >= 1
     - Optional device-side directory below the driver's recording root.
   * - ``marker``
     - null
     - length >= 1
     - Optional marker retained with the device recording.
   * - ``maxFileSizeBytes``
     - null
     - >= 1
     - Optional maximum raw-stream file size accepted by the device.
   * - ``nodeDestinationDirectory``
     - null
     - length >= 1
     - Optional NodeEngine-host transfer destination; defaults to the transfer child run directory.

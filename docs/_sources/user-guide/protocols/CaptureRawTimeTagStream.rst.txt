CaptureRawTimeTagStream
=======================

Resolve a link's TimeTagger channels from the active network, then declaratively start, hold, stop, and transfer one closed raw stream within the same lease-root instance.

Catalog location: ``acquisition.rawStream``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

     - Declared value
   * - Resource requests
     - ["$shared.timeTaggerDeviceId"]
   * - Execution mode
     - foreground
   * - Protocol timeout (s)
     - 86460.0

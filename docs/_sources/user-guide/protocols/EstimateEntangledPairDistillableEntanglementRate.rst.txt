EstimateEntangledPairDistillableEntanglementRate
================================================

``entanglement.distillation``

Estimate detected pair throughput and a one-way hashing lower bound from existing tomography.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** no device resources.

Estimates detected pair throughput and a best-direction one-way hashing lower bound in ebit per pair and ebit per second from an existing two-qubit density matrix and background-corrected tomography, without acquisition or physical distillation.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

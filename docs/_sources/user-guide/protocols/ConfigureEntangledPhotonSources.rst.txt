ConfigureEntangledPhotonSources
===============================

``device.configuration``

Configure entangled-photon sources, associated attenuators and clock settings.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Applies the requested operating configuration to entangled-photon sources, associated attenuators, and optional clock settings, and returns the applied parameter values.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``sources``
     - []
     - —
     - Entangled-photon source device configurations to apply. Null or omission means no sources requested. Non-null entries require deviceId; paired clockOutputFrequencyMHz/clockOutputAttenuationDb must both be supplied, or clockOutput must contain frequencyMHz and attenuationDb (clockFrequencyMHz/clockAttenuationDb aliases are also accepted). Dynamic parameters remain driver-owned.
   * - ``sources[]``
     - not declared
     - —
     - One source device and its requested operating parameters. Required when the containing object or array item is supplied.
   * - ``attenuators``
     - []
     - —
     - Attenuator device configurations associated with the sources. Null or omission means no attenuators requested. Every non-null entry requires deviceId; a missing/null attenuation requests no change.
   * - ``attenuators[]``
     - not declared
     - —
     - One attenuator device and its requested parameter value. Required when the containing object or array item is supplied.
   * - ``clock``
     - {}
     - —
     - Optional pump and reference-clock configuration for the source devices.
   * - ``settleSec``
     - 1
     - >= 0
     - Delay after applying the requested operating state, in seconds.

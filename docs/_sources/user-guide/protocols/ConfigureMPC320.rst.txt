ConfigureMPC320
===============

Applies optional velocity, home-position, and jog-size settings to one MPC320 polarization controller and returns the applied configuration.

Catalog location: ``device.configuration``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

MeasureLinkSingles
==================

``link.characterization``

Measure guarded singles counts and rates on resolved quantum links.

:bdg:`foreground` :bdg:`declared timeout 3 min`

:bdg:`Callable from Open libraries`

**Lease:** none of its own; child protocols lease the devices they use.

Measures finite singles counts and rates for resolved quantum links and returns their acquisition provenance. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 28 22 50
   :class: api-table protocol-input-table

   * - Input
     - Type
     - Meaning
   * - ``targetLinkIds``
     - string[] (items >= 1; each length >= 1)
     - Unique quantum-link identifiers whose TimeTagger sink channels are measured as singles. Each item: One target quantum-link identifier resolved from network.json.
   * - ``latchGuard``
     - object
     - Explicit finite-window latch policy propagated to background and tomography acquisitions. required rejects invalid windows and retries only after detector recovery; disabled deliberately acquires without latch protection.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether per-window detector-latch validation is disabled or required.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of an invalid window after a recovered latch.
   * - ``resourceDeviceIds``
     - string[] (items >= 1; each length >= 1)
     - Exact acquisition union: TimeTagger plus every network-resolved health guard when required. The acquisition child acquires or inherits these resources. Each item: One device needed by this acquisition or scan.

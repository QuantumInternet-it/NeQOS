InstallPolarizationAnalyzerCompensation
=======================================

``device.calibrationStore``

Install a validated compensated tomography-state table on an analyzer.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``polarizationAnalyzerDeviceId``.

Installs a validated compensated tomography-state table on one PA X000 or MPC320 polarization analyzer, optionally persists it on the DeviceOS host, and optionally applies a final compensated state.

2 What you get

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``polarizationAnalyzerChannel``
     - 1
     - >= 1
     - Analyzer channel. MPC320 supports only channel 1.
   * - ``persist``
     - true
     - —
     - Write the validated table to DeviceOS-local calibration storage after installation.
   * - ``finalTomographyState``
     - null
     - —
     - Optional compensated H/V/D/A/R/L state to apply after installation.
   * - ``sourceReport``
     - null
     - —
     - Optional provenance saved alongside the table on the DeviceOS host.
   * - ``validationReport``
     - null
     - —
     - Optional validation provenance persisted with the source report.

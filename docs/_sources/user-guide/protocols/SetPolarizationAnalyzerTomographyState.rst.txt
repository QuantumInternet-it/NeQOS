SetPolarizationAnalyzerTomographyState
======================================

``device.configuration``

Apply a named factory or compensated tomography state to an analyzer.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``polarizationAnalyzerDeviceId``.

Sets one PA X000 or MPC320 polarization-analyzer channel to a named factory or compensated tomography state and returns the applied device configuration.

3 Options
---------

.. list-table::

   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``polarizationAnalyzerChannel``
     - 1
     - >= 1
     - One-based polarization-analyzer channel to configure. MPC320 supports only channel 1.
   * - ``tomographyState``
     - "H"
     - length >= 1
     - Named tomography state to apply on the selected channel.
   * - ``useCompensated``
     - true
     - —
     - Whether the device uses its compensated rather than factory tomography table.

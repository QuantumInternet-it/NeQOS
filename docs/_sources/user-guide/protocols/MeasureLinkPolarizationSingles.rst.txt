MeasureLinkPolarizationSingles
==============================

``link.characterization``

Measure guarded link singles tomography across logical analyzer states.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Measures finite singles counts and rates across logical analyzer states for one or more analyzer-equipped target links. network.json declares each channel as polarizer or PBS: complementary PBS outputs are acquired together, reducing physical settings without changing the reported logical states. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

   :header-rows: 1

   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``targetLinkIds``
     - string[] (items >= 1)
     - Analyzer-equipped target quantum-link identifiers measured at each state.
   * - ``targetLinkIds[]``
     - string length >= 1
     - One target quantum-link identifier.
   * - ``polarizationAnalyzerDeviceIds``
     - string[] (items >= 1)
     - Analyzer devices leased while their target channels are configured and scanned.
   * - ``polarizationAnalyzerDeviceIds[]``
     - string length >= 1
     - One polarization-analyzer device identifier.
   * - ``latchGuard``
     - object
     - Explicit finite-window latch policy propagated to background and tomography acquisitions. required rejects invalid windows and retries only after detector recovery; disabled deliberately acquires without latch protection.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether per-window detector-latch validation is disabled or required.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of an invalid window after a recovered latch.
   * - ``resourceDeviceIds``
     - string[] (items >= 1)
     - Exact scan lease union: resolved analyzers and TimeTagger, plus every network-resolved health guard when required.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One device needed by this acquisition or scan.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``tomographyStates``
     - ["H", "V", "D", "A", "R", "L"]
     - items >= 1
     - Logical H/V/D/A/R/L projections to report. A PBS acquires complementary pairs from one physical H/D/R setting; a polarizer requires one setting per requested logical projection.
   * - ``tomographyStates[]``
     - not declared
     - length >= 1
     - One analyzer state accepted by the polarization analyzer. Required when the containing object or array item is supplied.
   * - ``measurementDurationSec``
     - 3
     - —
     - Finite singles acquisition duration for each analyzer state, in seconds.
   * - ``settleSec``
     - 1
     - >= 0
     - Non-blocking delay after each analyzer-state change and before its finite measurement window, in seconds. The default allows the polarization analyzer to settle physically.
   * - ``clear``
     - true
     - —
     - Whether every finite acquisition window starts from cleared measurements.
   * - ``useCompensatedTomoStates``
     - false
     - —
     - Whether named analyzer states are resolved from an installed or loaded compensation table instead of the factory tomography table.
   * - ``dwdmChannelByLink``
     - {}
     - —
     - Optional per-target DWDM channel overrides for analyzer wavelength configuration.
   * - ``defaultDwdmChannel``
     - null
     - >= 1
     - Optional fallback DWDM channel when a target link does not declare one in network.json.
   * - ``finalTomographyState``
     - null
     - length >= 1
     - Optional state applied to every target analyzer after the scan, including best-effort terminal cleanup after a failed or aborted scan.

TransferDeviceFileToNode
========================

``device.fileTransfer``

Transfer completed device files to the NodeEngine host and verify them.

:bdg:`foreground` :bdg:`declared timeout 2 min`

:bdg:`Callable from Open libraries`

.. note::

   The standalone input is a template: replace localPath with an existing closed file on TT-2's DeviceOS host. The Record then transfer run plan first records a one-second stream, then imports its real device artifact, including size/digest metadata, into this protocol. Adapt the example inventory endpoint and verify Time Tagger channel 1 before hardware use. It is not a copy of the laboratory inventory.

**Lease:** devices selected by ``deviceId``.

Transfer a completed device-side file or file set to the NodeEngine host and verify every declared member.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 28 22 50
   :class: api-table protocol-input-table

   * - Input
     - Type
     - Meaning
   * - ``deviceId``
     - string length >= 1
     - Device host from which the completed file is retrieved.
   * - ``deviceArtifact``
     - object
     - Device-produced file artifact containing one localPath or an ordered files list with per-file size/digest metadata. Each transferred entry requires localPath; fileName defaults to its basename, and sizeBytes/sha256 are optional verification metadata. All entries are checked before the first pull.

.. code-block:: json

   {
     "schemaVersion": "0.4",
     "metaProtocolLibrary": {
       "libraryId": "neqos-protected"
     },
     "steps": [
       {
         "protocolId": "TransferDeviceFileToNode",
         "sharedParams": {
           "deviceId": "TT-2",
           "deviceArtifact": {
             "localPath": "/path/on/device/closed-recording.ttbin"
           }
         }
       }
     ]
   }

TransferDeviceFileToNode
========================

Transfer a completed device-side file or file set to the NodeEngine host and verify every declared member.

Catalog location: ``device.fileTransfer``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

AlignSNSPDInputPolarization
===========================

``link.polarizationAlignment``

Align one SNSPD input polarization using its upstream MPC320 and count-rate feedback.

:bdg:`foreground` :bdg:`timeout 30 min`

**Lease:** devices selected by ``resourceMpcDeviceIds``.

Align the polarization incident on the SNSPD associated with one quantum link by scanning its upstream MPC320 and optimizing the measured count rate.

-------------

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.polarizationAlignment.\ **status**\ .alignment
     - Terminal alignment status and resolved topology target.
   * - link.polarizationAlignment.\ **applied**\ .selectedControllerAnglesDeg
     - Selected MPC320 angle for each requested paddle, in paddle order.
   * - link.polarizationAlignment.\ **observation**\ .countSamples
     - All count-rate samples acquired during the coarse and optional refinement scans.
   * - link.polarizationAlignment.\ **artifact**\ .scanPasses
     - NodeEngine-local JSON summaries and PNG scan curves written after each completed coarse or refinement pass.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 0.2
     - —
     - Integration duration for each SNSPD count sample, in seconds.
   * - ``optimizationMode``
     - "maximize"
     - "maximize" \| "minimize"
     - Whether the selected controller angles maximize or minimize the observed SNSPD count rate.
   * - ``initialPositionMode``
     - "explicit"
     - "explicit" \| "current"
     - Whether all selected paddles are moved to initialAnglesDeg before scanning, or remain at their current positions until their individual coarse scans begin.
   * - ``paddles``
     - [0, 1, 2]
     - items >= 1
     - MPC320 paddle indices to scan.
   * - ``paddles[]``
     - not declared
     - >= 0
     - One MPC320 paddle index. Required when the containing object or array item is supplied.
   * - ``initialAnglesDeg``
     - [0, 0, 0]
     - items >= 1
     - Initial scan angle for each selected paddle, in degrees.
   * - ``finalAnglesDeg``
     - [160, 160, 160]
     - items >= 1
     - Final scan angle for each selected paddle, in degrees.
   * - ``stepDeg``
     - 10
     - —
     - Coarse scan angular increment in degrees.
   * - ``refinements``
     - []
     - —
     - Ordered optional whole-controller passes; each pass scans every selected paddle around the corresponding preceding-pass optimum and is bounded by the coarse scan endpoints.
   * - ``refinements[]``
     - not declared
     - —
     - One refinement-pass configuration applied to every selected paddle. Required when the containing object or array item is supplied.
   * - ``refinements[].halfRangeDeg``
     - not declared
     - >= 0
     - Half-width of each paddle scan around its preceding-pass optimum, in degrees. Required when the containing object or array item is supplied.
   * - ``refinements[].stepDeg``
     - not declared
     - —
     - Angular increment for this local scan, in degrees. Required when the containing object or array item is supplied.
   * - ``settleAfterMoveSec``
     - 0.2
     - >= 0
     - Settling delay after each controller movement, in seconds.
   * - ``moveTimeoutSec``
     - 30
     - >= 0
     - Timeout for each MPC320 movement, in seconds. Null requests no per-move timeout override.

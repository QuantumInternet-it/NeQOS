AlignSNSPDInputPolarization
===========================

Align the polarization incident on the SNSPD associated with one quantum link by scanning its upstream MPC320 and optimizing the measured count rate.

Catalog location: ``link.polarizationAlignment``. This page documents the current exported Reserved contract, not a hardware-test certificate.

Before running
--------------

Read :doc:`../installation`, :doc:`../network` and :doc:`../running`. Start DeviceOS for the devices this run actually uses; a pure numerical protocol needs no hardware process. Explicit lease inputs must agree with the resolved topology.

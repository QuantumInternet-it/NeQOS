MeasureLinkBackgroundCoincidences
=================================

``link.characterization``

Measure link coincidence background while preserving and restoring the carrier state.

:bdg:`foreground` :bdg:`declared timeout 5 min`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``resourceDeviceIds``.

Measure coincidence background while holding the source and Time Tagger leases and attempting to restore the original source and inline-attenuator settings, including after failure. A required latchGuard or a nonempty detectorPairs list selects MeasureCoincidences, which receives the guard policy. Otherwise, unguarded H-sink acquisition uses MeasureLinkCoincidences, which does not accept latchGuard.

   * - ``referenceLinkId``
     - string length >= 1
     - Reference quantum link whose H TimeTagger sink is paired with every target-link sink.
   * - ``targetLinkIds``
     - string[] (items >= 1; each length >= 1)
     - Quantum links whose H TimeTagger sink channels are measured against referenceLinkId after all resolved sources are parked. Each item: One target quantum-link identifier resolved from network.json.
   * - ``resourceDeviceIds``
     - string[] (items >= 2; each length >= 1)
     - Exactly the sources resolved from referenceLinkId and targetLinkIds, every inline attenuator on their source-emitted links, and their one TimeTagger; this reserves the complete safe park/measurement/restore bracket. With latchGuard required, also include exactly the network health guards covering the selected channels; no analyzer lease is requested. Each item: One resolved source, its bound inline attenuator, or TimeTagger device identifier.

2 What you get
--------------

   :header-rows: 1
   :width: 100%

   * - Export key
     - Content
   * - link.characterization.\ **plan**\ .background
     - Resolved link pairs, sources, TimeTagger, resource bracket, and finite acquisition settings.
   * - link.characterization.\ **applied**\ .sourceParking
     - Source parking values applied before the background acquisition and subsequently restored.
   * - link.characterization.\ **observation**\ .background
     - Finite background counts indexed by physical detector pair, with source-parking provenance.
   * - link.characterization.\ **status**\ .restoration
     - Verified source-state restoration status and read-backs after the background observation.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 27 18 17 38
   :class: api-table protocol-input-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 1
     - > 0
     - Finite integration duration of each background coincidence observation, in seconds.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence window used for every reference-target pair, in picoseconds.
   * - ``settleSec``
     - 0.2
     - >= 0
     - Delay after parking the source carriers and before the finite acquisition, in seconds.
   * - ``restoreSettleSec``
     - 0.2
     - >= 0
     - Delay after verified carrier restoration before the protocol completes, in seconds.
   * - ``clear``
     - true
     - —
     - Whether the finite coincidence acquisition clears its stable measurements first.
   * - ``detectorPairs``
     - []
     - each object
     - Optional physical reference-target pairs acquired together by MeasureCoincidences. An empty list uses each link's H sink; required latchGuard still selects MeasureCoincidences. Each channel must belong to the selected link, and duplicate pairs are rejected. Each item: One network-validated physical detector pair.
   * - ``detectorPairs[].referenceChannel``
     - —
     - >= 0
     - TimeTagger channel on referenceLinkId. Include this field in each ``detectorPairs`` item.
   * - ``detectorPairs[].targetChannel``
     - —
     - >= 0
     - TimeTagger channel on one targetLinkId. Include this field in each ``detectorPairs`` item.
   * - ``latchGuard``
     - see fields below
     - —
     - Finite-window guard policy passed to MeasureCoincidences when the policy is required or nonempty detectorPairs is supplied. Required mode leases the network-selected health devices and rejects clear=false; disabled mode acquires without latch protection. The unguarded H-only MeasureLinkCoincidences path has no latchGuard input.
   * - ``latchGuard.mode``
     - "disabled"
     - "disabled" \| "required"
     - Whether detector-latch validation is disabled or required for this observation.
   * - ``latchGuard.maxWindowRetries``
     - 0
     - >= 0
     - Maximum immediate retries after a recovered detector latch; use zero to reject the first invalid window.

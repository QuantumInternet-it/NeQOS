MeasureLinkBackgroundCoincidences
=================================

``link.characterization``

Measure link coincidence background while preserving and restoring the carrier state.

:bdg:`foreground` :bdg:`timeout 5 min`

**Lease:** devices selected by ``resourceDeviceIds``.

Measures finite coincidence background between one reference link and one or more target links. The protocol snapshots both EPS attenuation paths, output mode, and every bound inline attenuator of each resolved source. Any traffic-mode change is first protected at declared source/attenuator maxima; it then parks the sources, composes MeasureLinkCoincidences for the requested pairs, and restores the exact live state. The source and TimeTagger leases remain owned for the complete park/acquire/restore bracket, including failure cleanup. Optional detectorPairs select physical reference-target channels validated against network bindings, including PBS/multibranch ports; these pairs are acquired together through MeasureCoincidences. latchGuard is forwarded unchanged, with the exact selected health-guard lease union.

1 Minimal run
-------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``referenceLinkId``
     - string length >= 1
     - Reference quantum link whose H TimeTagger sink is paired with every target-link sink.
   * - ``targetLinkIds``
     - string[] (items >= 1)
     - Quantum links whose H TimeTagger sink channels are measured against referenceLinkId after all resolved sources are parked.
   * - ``targetLinkIds[]``
     - string length >= 1
     - One target quantum-link identifier resolved from network.json.
   * - ``resourceDeviceIds``
     - string[] (items >= 2)
     - Exactly the sources resolved from referenceLinkId and targetLinkIds, every inline attenuator on their source-emitted links, and their one TimeTagger; this reserves the complete safe park/measurement/restore bracket. With latchGuard required, also include exactly the network health guards covering the selected channels; no analyzer lease is requested.
   * - ``resourceDeviceIds[]``
     - string length >= 1
     - One resolved source, its bound inline attenuator, or TimeTagger device identifier.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.characterization.\ **plan**\ .background
     - Resolved link pairs, sources, TimeTagger, resource bracket, and finite acquisition settings.
   * - link.characterization.\ **applied**\ .sourceParking
     - Source parking values applied before the background acquisition and subsequently restored.
   * - link.characterization.\ **observation**\ .background
     - Finite coincidence background with source-parking provenance.
   * - link.characterization.\ **status**\ .restoration
     - Verified source-state restoration status and read-backs after the background observation.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 1
     - —
     - Finite integration duration of each background coincidence observation, in seconds.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence window used for every reference-target pair, in picoseconds.
   * - ``settleSec``
     - 0.2
     - >= 0
     - Delay after parking the source carriers and before the finite acquisition, in seconds.
   * - ``restoreSettleSec``
     - 0.2
     - >= 0
     - Delay after verified carrier restoration before the protocol completes, in seconds.
   * - ``clear``
     - true
     - —
     - Whether the finite coincidence acquisition clears its stable measurements first.
   * - ``detectorPairs``
     - []
     - —
     - Optional physical reference-target pairs; empty retains the historical H-sink-per-link acquisition. Each channel must belong to the selected network link, and duplicate pairs are rejected.
   * - ``detectorPairs[]``
     - not declared
     - —
     - One network-validated physical detector pair. Required when the containing object or array item is supplied.
   * - ``detectorPairs[].referenceChannel``
     - not declared
     - >= 0
     - TimeTagger channel on referenceLinkId. Required when the containing object or array item is supplied.
   * - ``detectorPairs[].targetChannel``
     - not declared
     - >= 0
     - TimeTagger channel on one targetLinkId. Required when the containing object or array item is supplied.
   * - ``latchGuard``
     - {"maxWindowRetries": 0, "mode": "disabled"}
     - —
     - Finite-window guard policy forwarded to the acquisition. Default disabled preserves existing callers. Required adds the network-selected health devices to the exact resource union and rejects clear=false.
   * - ``latchGuard.mode``
     - "disabled"
     - "disabled" \| "required"
     - Whether detector-latch validation is disabled or required for this observation. Required when the containing object or array item is supplied.
   * - ``latchGuard.maxWindowRetries``
     - 0
     - >= 0
     - Maximum immediate retries after a recovered detector latch; use zero to reject the first invalid window. Required when the containing object or array item is supplied.

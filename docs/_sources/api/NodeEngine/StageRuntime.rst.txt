Stage handler runtime
=====================

A handler receives ``ctx`` and its effective ``params``. Import these public helper types from ``NodeEnginePack.NodeEngineAuxiliary``; the compiled distribution supplies this module.

:doc:`Write a meta-protocol </user-guide/writing-meta-protocols>` for complete static and dynamic examples.

``protocolId`` identifies this run; ``protocolTemplateId`` identifies its definition. ``stageIndex`` is zero-based. ``scratchpad`` persists across stages and requeues. ``lastStageResults`` is the earlier stage history; ``taskResults`` collects this handler invocation's device/import/publication results. ``nodeEngine`` is the runtime object, not an invitation to depend on private engine internals.

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Decision
     - Effect
   * - ``advance``
     - Continue with the next stage; after the last stage the run completes.
   * - ``repeat``
     - Run this stage again inside the running protocol; optional delaySec sleeps before repeating.
   * - ``requeue``
     - Return to scheduling at the same stage; optional delaySec delays eligibility. Prefer this while waiting for children.
   * - ``complete``
     - Complete early, skipping later stages. A parent cannot complete while a descendant is non-terminal. Publish required outputs before completing.
   * - ``fail``
     - Fail this protocol with reason; descendant abort and terminal lease cleanup follow the engine lifecycle.

``delaySec`` is optional and non-negative. A decision string is accepted for compatibility; return ``StageResult`` to specify a reason, delay or lease policy. An invalid decision or an unhandled handler exception fails the stage.

On ``requeue``, owned and delegated leases are retained by default. ``releaseResources=True`` explicitly yields them; do not use it while preserving an atomic sequence of child operations. ``retainResources`` is the older compatibility field, not required to retain an existing lease root. Release flags have no repeat/advance meaning.

External Python Package Dependency
==================================

Shows how a local handler in an Open library imports humanize, formats an integer and publishes its result without device operations.

Library ID: ``external-python-package-dependency``

Handler dependency
------------------

The local handler imports the package listed in :download:`requirements.txt <../../../../NodeEnginePack/OpenMetaProtocols/ExternalPythonPackageDependency/requirements.txt>`. Source runs use the selected Python environment. A standalone NodeEngine searches the ExternalPythonPackageDependency directory beside its executable or source entry point; the activated Conda environment alone does not make a package available there.

For a standalone distribution, prepare that separate directory using its matching Python/platform and the shipped requirements:

.. code-block:: bash

   python -m pip install --target /path/to/NodeEngine.dist/ExternalPythonPackageDependency -r ./NodeEnginePack/OpenMetaProtocols/ExternalPythonPackageDependency/requirements.txt

This preparation command is not a NeQOS run and does not install into the active Python environment. Use the directory for the handler's additional dependency, not to replace core NeQOS packages.

Run the shipped examples

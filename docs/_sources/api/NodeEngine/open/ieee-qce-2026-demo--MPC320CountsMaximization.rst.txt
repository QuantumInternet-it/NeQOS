MPC320CountsMaximization
========================

Library: ``ieee-qce-2026-demo``

Open IEEE QCE demonstration wrapper for aligning the polarization incident on the SNSPD of one selected quantum link.

:bdg:`foreground` :bdg:`timeout 60 min`

**Lease:** no device resources.

1 Required inputs
-----------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Type
     - Meaning
   * - ``linkId``
     - string length >= 1
     - Quantum link whose SNSPD input polarization is aligned.
   * - ``resourceDeviceIds``
     - value[] (items >= 2)
     - MPC320 and TimeTagger identifiers reserved by the protected child.

:doc:`Input defaults and launching </user-guide/running>`.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - ``link.polarizationAlignment.status.alignment``
     - Terminal alignment status and resolved target.
   * - ``link.polarizationAlignment.applied.selectedControllerAnglesDeg``
     - Selected MPC320 angles, in paddle order.
   * - ``link.polarizationAlignment.observation.countSamples``
     - Count samples collected by the alignment scan.

Declared keys are present after successful completion; values may be null or empty. See :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 2.0
     - >= 0
     - Integration duration of each count sample, in seconds.
   * - ``optimizationMode``
     - "maximize"
     - "maximize" \| "minimize"
     - Whether the child maximizes or minimizes the SNSPD count rate.
   * - ``paddles``
     - [0, 1, 2]
     - items >= 1
     - MPC320 paddle indices to scan.
   * - ``initialAnglesDeg``
     - [0.0, 0.0, 0.0]
     - items >= 1
     - Initial angle per paddle, in degrees.
   * - ``finalAnglesDeg``
     - [160.0, 160.0, 160.0]
     - items >= 1
     - Final angle per paddle, in degrees.
   * - ``stepDeg``
     - 20.0
     - >= 1e-06
     - Coarse angular scan increment in degrees.
   * - ``settleAfterMoveSec``
     - 0.2
     - >= 0
     - Settling delay after each movement, in seconds.
   * - ``moveTimeoutSec``
     - 30.0
     - >= 0
     - Timeout per controller movement, in seconds.

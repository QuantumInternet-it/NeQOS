FAKE-STAGED
===========

Library: ``fake-device-examples``

Multi-stage FakeDriver foreground protocol mixing short and pausable long tasks.

:bdg:`foreground` :bdg:`declared timeout 2 min`

:bdg:`preemptive`

Pausable device tasks may enter PAUSED/PREEMPTED and later RESUMED; the driver and task must support pause/resume. See :doc:`/user-guide/writing-hardware-driver`.

**Lease:** ``FakeDeviceId``.

4 Run examples
--------------

Library folders resolve relative to the run input. Keep the library's directory layout when using its shipped input and network. Commands below are for a source checkout, from the repository root. For compiled distributions, follow :doc:`/user-guide/quickstart`: DeviceOS uses ``OpenDrivers/OpenDrivers.json`` beside its executable and reads the network using an explicit path to the NodeEngine distribution or a shared JSON. Copying ``NodeEnginePack`` into DeviceOS is unnecessary. These commands execute the run, not an offline validation.

:download:`Download shipped input.json <../../../../NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/MetaProtocolsRun/staged/input.json>`

Inventory: :download:`lab-inventory.json <../../../../NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/lab-inventory.json>`.
Experiment network: :download:`network.json <../../../../NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/network.json>`.

Start one DeviceOS process for each enabled device below, on its configured host. Wait for connected, initialized and ready state before starting NodeEngine.

**FakeDeviceId** (``Fake`` driver):

.. code-block:: bash

   python3 -m DeviceOSPack.DeviceOS \
     --inventoryFile ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/lab-inventory.json \
     --nodeId FakeNodeId \
     --deviceId FakeDeviceId \
     --licenseFile /path/to/license.json \
     --openDriversFile ./DeviceOSPack/OpenDrivers/OpenDrivers.json

Then start NodeEngine:

.. code-block:: bash

   python3 -m NodeEnginePack.NodeEngine \
     --inventoryFile ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/lab-inventory.json \
     --networkFile ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/network.json \
     --nodeId FakeNodeId \
     --licenseFile /path/to/license.json \
     --metaProtocolRun ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/MetaProtocolsRun/staged/input.json \
     --openDriversFile ./DeviceOSPack/OpenDrivers/OpenDrivers.json \
     --waitProtocol

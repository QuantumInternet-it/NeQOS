Fake Device Examples
--------------------

Examples on the software-only FakeDriver: built-in stage handlers, local Python handlers, multi-stage/preemptible execution and passing declared results from children to their parent.

      :link-type: doc

      .. _fake-composed-sweep-branch:

      :link-type: doc

      .. _fake-composed-sweep-leaf:

Behavior
--------

The stage advances immediately; pair it with WaitMicroProtocolStage using the
same protocolKey. Open callers may invoke their own library's protocols and
public built-in protocols. Shared and scratch references are resolved before
submission. An omitted resourceRequests uses the child declaration; an explicit
list replaces it. An empty list grants no permission to operate parent devices.

State and results
-----------------

Stores the runtime ID at _mp_<protocolKey>. Imported scratchpad values initialize
the child's private state; they are not public result imports. The parent
retains its lease root while a declared foreground child uses a delegated turn.

Failure conditions
------------------

Missing templateId, invalid override/resource/mapping values or unavailable
referenced paths fail the stage. Child contract, visibility and submission
errors propagate to NodeEngine's stage-failure handling.

:doc:`Runtime context, decisions and leases </api/NodeEngine/StageRuntime>`.

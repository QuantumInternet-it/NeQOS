RunSingleTaskStage
==================

Run one device task; by default, fail unless its outer reply status is OK.

Behavior
--------

NodeEngine resolves shared references in effective stage parameters before this
handler is called. This handler does not resolve scratch references; use a local
handler with ctx.get when task inputs depend on the scratchpad. It checks only
the outer status, not result.status; task-specific payload checks need a handler.

State and results
-----------------

Awaits ctx.run_task, which records the normalized reply in taskResults.
When resultKey is non-empty, stores the reply wrapper even for a task error.
Disabling failOnTaskError leaves error handling to subsequent stages; it does
not turn an error reply into successful device execution.

Failure conditions
------------------

A non-OK outer reply fails when failOnTaskError is enabled. Missing required
keys, invalid taskParams, unknown tasks, inactive leases, transport errors
and invalid returned decisions may fail at the runtime boundary.

:doc:`Runtime context, decisions and leases </api/NodeEngine/StageRuntime>`.

      async def RunSingleTaskStage(ctx: StageContext, params: Dict[str, Any]) -> StageResult:
          """Run one device task; by default, fail unless its outer reply status is OK.
      
          NodeEngine resolves shared references in effective stage parameters before this
          handler is called. This handler does not resolve scratch references; use a local
          handler with ctx.get when task inputs depend on the scratchpad. It checks only
          the outer status, not result.status; task-specific payload checks need a handler.
      
          Parameters:
              deviceId (string; required): Device declared as a resource of this protocol; this run must have its active turn.
              taskName (string; required): Advertised driver task name.
              taskParams (object; default: {}): Arguments sent to the device task.
              resultKey (string; default: ""): Optional scratchpad path storing deviceId, taskName and the normalized reply.
              failOnTaskError (boolean; default: true): Fail on a non-OK outer status; interpreted by its truth value.
              decision (string; default: "advance"): Decision returned after the reply check; must be a supported StageResult decision.
      
          State and results:
              Awaits ctx.run_task, which records the normalized reply in taskResults.
              When resultKey is non-empty, stores the reply wrapper even for a task error.
              Disabling failOnTaskError leaves error handling to subsequent stages; it does
              not turn an error reply into successful device execution.
      
          Failure conditions:
              A non-OK outer reply fails when failOnTaskError is enabled. Missing required
              keys, invalid taskParams, unknown tasks, inactive leases, transport errors
              and invalid returned decisions may fail at the runtime boundary.
          """
          deviceId = str(params["deviceId"])
          taskName = str(params["taskName"])
          reply = await ctx.run_task(
              deviceId=deviceId,
              taskName=taskName,
              params=dict(params.get("taskParams") or {}),
          )
          resultKey = str(params.get("resultKey") or "").strip()
          if resultKey:
              ctx.set(resultKey, {
                  "deviceId": deviceId,
                  "taskName": taskName,
                  "reply": reply,
              })
          if bool(params.get("failOnTaskError", True)) and str(reply.get("status") or "").upper() != "OK":
              return StageResult(
                  decision="fail",
                  reason=(
                      f"{taskName} failed on {deviceId}: "
                      f"{reply.get('errorType')} {reply.get('errorMessage')}"
                  ),
              )
          return StageResult(decision=str(params.get("decision") or "advance"))

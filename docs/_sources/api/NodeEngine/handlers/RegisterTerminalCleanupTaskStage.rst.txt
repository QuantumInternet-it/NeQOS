RegisterTerminalCleanupTaskStage
================================

Register an idempotent device task for terminal protocol cleanup.

Behavior
--------

The task is executed by NodeEngine while the lease root is still valid if
the current protocol aborts, fails, or is forcibly released.  It is useful
for a declared child workflow which temporarily opens device-side state
that must be closed before the physical device lease is relinquished.

----------------------

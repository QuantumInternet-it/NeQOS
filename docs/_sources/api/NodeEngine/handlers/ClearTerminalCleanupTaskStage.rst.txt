ClearTerminalCleanupTaskStage
=============================

Remove a cleanup registration after successful normal restoration.

Behavior
--------

The complete normalized deviceId, taskName and taskParams must match the
registration. Clearing does not execute or verify the restoring operation.
Shared and scratch references are resolved at handler execution.

State and results
-----------------

Removes the matching executeTask action and writes the updated run manifest.
A non-matching action leaves the registration unchanged and still advances.

Failure conditions
------------------

Missing/empty deviceId or taskName, invalid taskParams or unresolved references
fail. A missing current runtime is a no-op in the underlying clearing API;
this does not constitute a successful hardware restoration.

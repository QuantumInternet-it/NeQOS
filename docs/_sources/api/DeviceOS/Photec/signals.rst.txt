Photec Signals
==============

.. admonition:: Signal reference
   :class: api-reference

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-signal-table
      :widths: 25 18 15 42

      * - Name
        - Type
        - Unit
        - Description
      * - ``alert``
        - ``object``
        - —
        - Alert created for the current invalid health reading, when present.
      * - ``allCounts``
        - ``object``
        - —
        - Latest counts for all 16 controller channels, keyed by 1-based channel number.
      * - ``countIntegrationTimeMs``
        - ``int``
        - —
        - Integration associated with this count sample.
      * - ``countSampleEpoch``
        - ``float``
        - —
        - Controller read time, not telemetry publication time.
      * - ``countSampleId``
        - ``str``
        - —
        - Identity of the actual controller read; unchanged for cached telemetry.
      * - ``countSampleValid``
        - ``bool``
        - —
        - False during integration settling or invalid detector health.
      * - ``counts``
        - ``object``
        - —
        - Latest counts for latchGuardChannels, keyed by 1-based channel number.
      * - ``discardedReadings``
        - ``list``
        - —
        - Invalid readings retained while automatic recovery is attempted.
      * - ``invalidatesMeasurements``
        - ``bool``
        - —
        - Whether the most recent latch result requires concurrent TimeTagger measurements to be discarded.
      * - ``lastAlert``
        - ``object``
        - —
        - Most recently recorded latch alert, including after a later valid reading.
      * - ``latchEventCount``
        - ``int``
        - —
        - Number of invalid latch detections since the latest driver initialization.
      * - ``latchGuardChannels``
        - ``list``
        - —
        - Configured 1-based channels monitored for latch detection.
      * - ``latchedChannels``
        - ``list``
        - —
        - Latch guard channels detected as latched in the most recent health reading.
      * - ``readingCorrupted``
        - ``bool``
        - —
        - Inverse of readingValid for the most recent health reading.
      * - ``readingValid``
        - ``bool``
        - —
        - Whether the most recent health reading contains no latched guard channel.
      * - ``recoveryStatus``
        - ``str``
        - —
        - Recovery outcome of the latest health read: NOT_NEEDED, PENDING, RECOVERED, or FAILED; historical recovery evidence is returned by ReadDetectorHealth.lastRecovery.

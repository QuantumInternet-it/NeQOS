.. _deviceos-swabiantt-createlogicalchannel:

.. admonition:: ``CreateLogicalChannel``
   :class: driver-overview task-reference

   Create or reuse a named logical channel.

   AND accepts one or more input references and uses coincidenceWindowPs or
   defaultCoincidenceWindowPs. OR ignores coincidenceWindowPs; NOT requires
   exactly one input reference. Supplying an existing name with identical
   configuration returns its channel reference with ``reused=True``.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. rubric:: Parameters
      :class: invocation-heading

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``operator``
        - ``str``
        - Yes
        - —
        - Logical operator ``AND``, ``OR``, or ``NOT``.
      * - ``inputRefs``
        - ``List[Any]``
        - Yes
        - —
        - Non-empty references to channels known to this driver.
      * - ``coincidenceWindowPs``
        - ``Optional[int]``
        - No
        - ``None``
        - Coincidence window in ps for ``AND``; omit to use ``defaultCoincidenceWindowPs``. It is ignored by ``OR`` and ``NOT``.
      * - ``name``
        - ``Optional[str]``
        - No
        - ``None``
        - Optional stable logical-channel reference; an existing name can be reused only with identical configuration.

.. _deviceos-swabiantt-createmeasurement:

.. admonition:: ``CreateMeasurement``
   :class: driver-overview task-reference

   Create or reuse one synchronized COUNTRATE or CORRELATION measurement.

   COUNTRATE requires channelRef. CORRELATION requires channelRefA and
   channelRefB; omitted binWidthPs and binCount use the documented default
   parameters. An existing name may be reused only with identical settings.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. rubric:: Parameters
      :class: invocation-heading

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``measurementType``
        - ``str``
        - Yes
        - —
        - Measurement kind ``COUNTRATE`` or ``CORRELATION``.
      * - ``channelRef``
        - ``Any``
        - No
        - ``None``
        - Channel reference required by ``COUNTRATE``.
      * - ``channelRefA``
        - ``Any``
        - No
        - ``None``
        - First channel reference required by ``CORRELATION``.
      * - ``channelRefB``
        - ``Any``
        - No
        - ``None``
        - Second channel reference required by ``CORRELATION``.
      * - ``binWidthPs``
        - ``Optional[int]``
        - No
        - ``None``
        - Correlation bin width in ps; omit to use the configured default. Ignored by ``COUNTRATE``.
      * - ``binCount``
        - ``Optional[int]``

.. _deviceos-swabiantt-resetmeasurementengine:

.. admonition:: ``ResetMeasurementEngine``
   :class: driver-overview task-reference

   Reopen the measurement engine and discard its derived state.

   Logical channels, measurement definitions, and active-measurement
   selections are released. Physical trigger levels and input delays are
   read before the reset, restored afterward, and returned as readback.

   :Admission policy: ``sync``
   :Pausable: No

.. _deviceos-swabiantt-startmeasurement:

.. admonition:: ``StartMeasurement``
   :class: driver-overview task-reference

   Acquire all active synchronized measurements for durationSec.

   clear resets compatible measurement handles before acquisition. With
   rawDataMode ``node``, correlation arrays are returned in the result;
   with ``device``, raw correlation data and a preview are scheduled as
   device artifacts and artifactWriteState is initially ``pending``.

   :Task class: Foreground
   :Admission policy: ``async``
   :Pausable: No

   .. rubric:: Parameters
      :class: invocation-heading

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``durationSec``
        - ``float``
        - Yes
        - —
        - Positive acquisition duration in seconds.
      * - ``clear``
        - ``bool``
        - No
        - ``True``
        - Clear compatible measurement handles before acquisition.
      * - ``rawDataMode``
        - ``str``
        - No
        - ``'node'``
        - ``node`` returns correlation data in the reply; ``device`` schedules raw data and preview artifacts on disk.

   positive. recordingSubdirectory is sanitized below the recording root.
   The result includes a transfer-ready manifest with path, SHA-256, size,
   channel mapping, duration, and FileWriter statistics.

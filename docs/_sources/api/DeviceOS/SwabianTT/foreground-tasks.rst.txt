.. _deviceos-swabiantt-createlogicalchannel:

.. admonition:: ``CreateLogicalChannel``
   :class: driver-overview task-reference

   Create or reuse a named logical channel.

   AND accepts one or more input references and uses coincidenceWindowPs or
   defaultCoincidenceWindowPs. OR ignores coincidenceWindowPs; NOT requires
   exactly one input reference. Supplying an existing name with identical
   configuration returns its channel reference with ``reused=True``.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``operator``
        - ``str``
        - Yes
        - —
        - —
      * - ``inputRefs``
        - ``List[Any]``
        - Yes
        - —
        - —
      * - ``coincidenceWindowPs``
        - ``Optional[int]``
        - No
        - ``None``
        - —
      * - ``name``
        - ``Optional[str]``
        - No
        - ``None``
        - —

   :Result keys: ``channelId``, ``channelRef``, ``implementation``, ``inputRefs``, ``operator``, ``resolvedInputChannels``, ``reused``, ``status``

   .. rubric:: Examples
      :class: examples-heading

.. _deviceos-swabiantt-resetmeasurementengine:

.. admonition:: ``ResetMeasurementEngine``
   :class: driver-overview task-reference

   Reopen the measurement engine and discard its derived state.

   Logical channels, measurement definitions, and active-measurement
   selections are released. Physical trigger levels and input delays are
   read before the reset, restored afterward, and returned as readback.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   No public parameters.

   .. rubric:: Examples
      :class: examples-heading

   The enclosing micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the task is advertised.

   Replace each ``<...>`` placeholder with a value accepted by the corresponding parameter.

   .. rubric:: Static task invocation from a micro-protocol declaration
      :class: invocation-heading

   .. code-block:: json

      {
        "stageId": "<stage-id>",
        "handler": "RunSingleTaskStage",
        "params": {
          "deviceId": "<device-id>",
          "taskName": "ResetMeasurementEngine",
          "taskParams": {}
        }
      }

   .. rubric:: Dynamic task invocation from a Python handler

.. _deviceos-swabiantt-startmeasurement:

.. admonition:: ``StartMeasurement``
   :class: driver-overview task-reference

   Acquire all active synchronized measurements for durationSec.

   clear resets compatible measurement handles before acquisition. With
   rawDataMode ``node``, correlation arrays are returned in the result;
   with ``device``, raw correlation data and a preview are scheduled as
   device artifacts and artifactWriteState is initially ``pending``.

   :Task class: Foreground
   :Admission policy: ``async``
   :Pausable: No

.. _deviceos-swabiantt-recordtimetagstream:

.. admonition:: ``RecordTimeTagStream``
   :class: driver-overview task-reference

   Record selected channels to one local .ttbin artifact.

   channelRefs must resolve to at least one channel and durationSec must be
   positive. recordingSubdirectory is sanitized below the recording root.
   The result includes a transfer-ready manifest with path, SHA-256, size,
   channel mapping, duration, and FileWriter statistics.

SwabianTT Foreground Tasks
==========================

CreateLogicalChannel
^^^^^^^^^^^^^^^^^^^^

Create a logical channel from existing physical/logical channels using AND, OR, or NOT.

Create or reuse a named logical channel.

AND accepts one or more input references and uses coincidenceWindowPs or
defaultCoincidenceWindowPs. OR ignores coincidenceWindowPs; NOT requires
exactly one input reference. Supplying an existing name with identical
configuration returns its channel reference with ``reused=True``.

Admission policy: ``sync``
Pausable: ``False``

.. list-table::
   :header-rows: 1

   * - Parameter
     - Type
     - Required
     - Default
   * - operator
     - str
     - Yes
     - -
   * - inputRefs
     - List[Any]
     - Yes
     - -
   * - coincidenceWindowPs
     - Optional[int]
     - No
     - None
   * - name
     - Optional[str]
     - No
     - None

Returns: ``Dict[str, Any]``

CreateMeasurement
^^^^^^^^^^^^^^^^^

Create a synchronized Swabian measurement on an existing physical or logical channel.

Create or reuse one synchronized COUNTRATE or CORRELATION measurement.

COUNTRATE requires channelRef. CORRELATION requires channelRefA and
channelRefB; omitted binWidthPs and binCount use the documented default
parameters. An existing name may be reused only with identical settings.

ResetMeasurementEngine
^^^^^^^^^^^^^^^^^^^^^^

Reopen the Time Tagger measurement engine and restore physical-channel trigger levels and input delays.

Reopen the measurement engine and discard its derived state.

Logical channels, measurement definitions, and active-measurement
selections are released. Physical trigger levels and input delays are
read before the reset, restored afterward, and returned as readback.

Admission policy: ``sync``
Pausable: ``False``

No public parameters.

Returns: ``Dict[str, Any]``

ActivateMeasurements
^^^^^^^^^^^^^^^^^^^^

Activate the subset of created measurements that will run during the next StartMeasurement window.

Select the created measurements used by StartMeasurement.

The supplied references replace the active selection. Unknown references
fail the task; duplicates are removed while preserving their first order.

Admission policy: ``sync``
Pausable: ``False``

.. list-table::
   :header-rows: 1

   * - Parameter
     - Type
     - Required
     - Default
   * - measurementRefs
     - List[str]
     - Yes
     - -

Returns: ``Dict[str, Any]``

StartMeasurement
^^^^^^^^^^^^^^^^

Run the active synchronized measurements for a fixed duration and return counts/coincidences.

Acquire all active synchronized measurements for durationSec.

clear resets compatible measurement handles before acquisition. With
rawDataMode ``node``, correlation arrays are returned in the result;
with ``device``, raw correlation data and a preview are scheduled as
device artifacts and artifactWriteState is initially ``pending``.

Admission policy: ``async``
Pausable: ``False``

.. list-table::
   :header-rows: 1

   * - Parameter
     - Type
     - Required
     - Default
   * - durationSec
     - float
     - Yes
     - -
   * - clear
     - bool
     - No
     - True
   * - rawDataMode
     - str
     - No
     - 'node'

Returns: ``Dict[str, Any]``

RecordTimeTagStream
^^^^^^^^^^^^^^^^^^^

Record selected Time Tagger channels to a local .ttbin file and return a transfer manifest.

Record selected channels to one local .ttbin artifact.

channelRefs must resolve to at least one channel and durationSec must be
positive. recordingSubdirectory is sanitized below the recording root.
The result includes a transfer-ready manifest with path, SHA-256, size,
channel mapping, duration, and FileWriter statistics.

Admission policy: ``async``
Pausable: ``False``

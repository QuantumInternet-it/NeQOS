   :Result keys: ``gain``, ``status``

   .. rubric:: Examples
      :class: examples-heading

   The enclosing micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the task is advertised.

   Replace each ``<...>`` placeholder with a value accepted by the corresponding parameter.

   .. rubric:: Static task invocation from a micro-protocol declaration
      :class: invocation-heading

   .. code-block:: json

      {
        "stageId": "<stage-id>",
        "handler": "RunSingleTaskStage",
        "params": {
          "deviceId": "<device-id>",
          "taskName": "SetGainTask",
          "taskParams": {
            "value": "<float>"
          }
        }
      }

   .. rubric:: Dynamic task invocation from a Python handler
      :class: invocation-heading

   .. code-block:: python

      reply = await ctx.run_task(
          deviceId="<device-id>",
          taskName="SetGainTask",
          params={
              "value": "<float>",
          },
      )

.. _deviceos-fake-firstforegroundlongpausabletask:

.. admonition:: ``FirstForegroundLongPausableTask``
   :class: driver-overview task-reference

   Example long foreground task with pause/resume support.

   Behavior:
   - At first start, seeds a random value.
   - On PAUSE cancellation, stores current state in _taskPauseStatesByProtocol.
   - On RESUME fallback, DeviceEngine injects `_pauseState` and the task continues from there.

   :Task class: Foreground
   :Admission policy: ``async``
   :Pausable: Yes

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``durationSec``
        - ``float``
        - No
        - ``120.0``
        - —
      * - ``tickSec``
        - ``float``
        - No
        - ``1.0``
        - —
      * - ``_pauseState``
        - ``Dict[str, Any] \| None``
        - No
        - ``None``
        - —

   :Result keys: ``durationSec``, ``reason``, ``seedValue``, ``status``, ``task``, ``ticks``

   .. rubric:: Examples

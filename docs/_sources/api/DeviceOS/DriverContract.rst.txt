Open driver contract
====================

Source drivers implement the ``0.6.0`` DeviceDriver API. Inheritance from ``HardwareDriver`` is optional; the external-driver validator checks the initialized instance, not its base class.

:doc:`Write a hardware driver </user-guide/writing-hardware-driver>` for a complete software-only example and lifecycle rules.

Task and capability declarations
--------------------------------

Each registry task is an async callable accepting ``context`` as a keyword. ``GetCapabilities`` returns parameter/signal metadata and the task maps ``foregroundTasks`` and ``backgroundTasks``. Task entries name the method exactly; the driver validates values and implements the operation.

.. code-block:: python

   def foreground_task(func: Callable | None=None, *, admissionPolicy: str, pausable: bool, description: str, resultSchema: Optional[Dict[str, Dict[str, Any]]]=None)

.. code-block:: python

   def background_task(func: Callable | None=None, *, blocking: bool, frequencyHz: float, maxRepetitions: int | None=None, expiresAfterSec: float | None=None, description: str, resultSchema: Optional[Dict[str, Dict[str, Any]]]=None)

The decorators above are optional base-class helpers. A plain-contract driver constructs equivalent registry metadata directly. ``resultSchema`` describes task-specific return fields, not a transport reply.

Required method names and state fields are extracted from ``DeviceOSPack/DeviceOS.py``; signatures are extracted from ``DeviceOSPack/HardwareDriver.py``.

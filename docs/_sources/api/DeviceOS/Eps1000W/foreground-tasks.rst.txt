Eps1000W Foreground Tasks
=========================

.. _deviceos-eps1000w-setoutputhh:

.. admonition:: ``setOutputHH``
   :class: driver-overview task-reference

   Select the ``HH`` output mode and return the device readback.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   No public parameters.

   .. rubric:: Examples
      :class: examples-heading

   The enclosing micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the task is advertised.

   Replace each ``<...>`` placeholder with a value accepted by the corresponding parameter.

   .. rubric:: Static task invocation from a micro-protocol declaration
      :class: invocation-heading

   .. code-block:: json

      {
        "stageId": "<stage-id>",
        "handler": "RunSingleTaskStage",
        "params": {
          "deviceId": "<device-id>",
          "taskName": "setOutputHH",
          "taskParams": {}
        }
      }

   .. rubric:: Dynamic task invocation from a Python handler
      :class: invocation-heading

   .. code-block:: python

      reply = await ctx.run_task(
          deviceId="<device-id>",
          taskName="setOutputHH",
          params={
          },
      )

.. _deviceos-eps1000w-realign:

.. admonition:: ``reAlign``
   :class: driver-overview task-reference

   Run the device realignment command and then read its output mode.

   The result includes the direct reply from ``Realign`` and the subsequent
   ``ReadOutputMode`` value. It does not modify other EPS parameters.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   No public parameters.

   :Result keys: ``outputMode``, ``reply``, ``status``, ``task``

   .. rubric:: Examples

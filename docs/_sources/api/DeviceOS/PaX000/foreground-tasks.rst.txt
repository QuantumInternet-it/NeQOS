.. _deviceos-pax000-settomographystate:

.. admonition:: ``setTomographyState``
   :class: driver-overview task-reference

   Apply one H, V, D, A, R, or L tomography state to a channel.

   ``state`` is case-insensitive; the canonical values are ``H``, ``V``,
   ``D``, ``A``, ``R``, and ``L``. With useCompensated enabled, the driver
   applies installed compensated waveplate angles when that state is
   available for the channel; otherwise it falls back to the controller's
   native tomography state. The result reports which mode was applied and
   the resulting waveplate angles.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``channel``
        - ``int``
        - Yes
        - —
        - —
      * - ``state``
        - ``Literal['H', 'V', 'D', 'A', 'R', 'L']``
        - Yes
        - —
        - —
      * - ``useCompensated``
        - ``bool``
        - No
        - ``True``
        - —

   .. rubric:: Examples
      :class: examples-heading

.. _deviceos-pax000-installcompensatedtomographystates:

.. admonition:: ``installCompensatedTomographyStates``
   :class: driver-overview task-reference

   Validate and install all compensated H/V/D/A/R/L states for one channel.

   ``states`` must contain the canonical keys ``H``, ``V``, ``D``, ``A``,
   ``R``, and ``L``. Each key maps one-based waveplate numbers to angles in
   degrees. For each state, every available waveplate among the first three
   must be present and each angle must be in the inclusive 0 to 360 degree
   range.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``channel``
        - ``int``
        - Yes
        - —
        - Controller channel that receives the compensated states.
      * - ``states``
        - ``Dict[str, Dict[int, float]]``
        - Yes
        - —
        - Mapping from each canonical tomography state to one-based waveplate numbers and their angles in degrees.
      * - ``persist``
        - ``bool``
        - No
        - ``True``
        - Write the validated states to the local persistence file.
      * - ``sourceReport``
        - ``Optional[Dict[str, Any]]``
        - No
        - ``None``
        - Optional free-form provenance metadata persisted with the states when ``persist`` is enabled.

   :Result keys: ``channel``, ``persisted``, ``persistenceFile``, ``states``, ``status``

   .. rubric:: Examples

        "handler": "RunSingleTaskStage",

.. _deviceos-pax000-loadpersistedcompensatedtomographystates:

.. admonition:: ``loadPersistedCompensatedTomographyStates``
   :class: driver-overview task-reference

   Load persisted compensated states for selected channels or all channels.

   This explicit task ignores the optional boot-load filter. The persisted
   file must match the supported schema, device ID, and, when present, the
   connected controller serial number. ``applyState`` is case-insensitive;
   it may be ``H``, ``V``, ``D``, ``A``, ``R``, or ``L`` and applies that
   loaded compensated state to every loaded channel.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

        - Required
        - Default
        - Description
      * - ``channels``
        - ``Optional[List[int]]``
        - No
        - ``None``
        - —
      * - ``applyState``
        - ``Optional[Literal['H', 'V', 'D', 'A', 'R', 'L']]``
        - No
        - ``None``
        - —

.. _deviceos-pax000-readopticalconfiguration:

.. admonition:: ``readOpticalConfiguration``
   :class: driver-overview task-reference

   Return the cached optical and compensation configuration.

   With channel omitted, the response covers every configured controller
   channel; otherwise it covers one validated channel. This task serializes
   cached identity, calibration, waveplate, wavelength, and compensated
   tomography information without a new serial hardware read.

   :Task class: Foreground
   :Admission policy: ``sync``

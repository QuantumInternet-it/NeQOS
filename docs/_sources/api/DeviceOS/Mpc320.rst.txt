Mpc320 Driver
=============

Control a Thorlabs MPC320 three-paddle polarization controller.

This driver exposes absolute and relative paddle moves, polarizer
configuration, and position or connection readback through DeviceOS.

The runtime declarations are the source of truth for generated driver
documentation: ``_PARAMETER_SPECS`` defines configurable parameters,
``_SIGNAL_SPECS`` defines readable signals, and ``@foreground_task``
declares the exported tasks together with their admission policy.

Source: ``DeviceOSPack/Mpc320Driver.py``

Official product page: `Thorlabs <https://www.thorlabs.com/thorproduct.cfm?partnumber=MPC320>`_

Exported Tasks
--------------

SetParameters
^^^^^^^^^^^^^

Apply MPC320 polarizer parameters (velocity/home/jog sizes) with optional overrides. Any parameter set to None keeps the current configured value.

Apply optional polarizer configuration overrides.

The task holds the driver I/O lock while it calls the vendor API. An
argument set to ``None`` keeps the corresponding configured value.
On success, the result contains the resolved serial number and all
five applied polarizer settings. A cancelled context returns
``CANCELLED``; a rejected or unavailable device raises ``RuntimeError``.

Admission policy: ``sync``

MoveTo
^^^^^^

Move one MPC320 paddle to an absolute angle.

Move one paddle to an absolute target angle.

The task holds the driver I/O lock for both the movement and its
position readback. When ``timeout`` is omitted it uses
``operation_timeout``. The target angle is constrained to the
configured 0--160 degree range. A requested displacement smaller than
``minimum_step`` is accepted without issuing a vendor movement.

The result contains ``status``, the resolved serial number, normalized
paddle index, requested target angle, reported position, and effective
timeout. Movement failures are reported with ``status: ERROR``;
a cancelled context returns ``CANCELLED``.

Admission policy: ``async``

MoveRelative
^^^^^^^^^^^^

Move one MPC320 paddle by a relative angle.

Move one paddle by a relative angle.

The task holds the driver I/O lock for both the movement and its
position readback. When ``timeout`` is omitted it uses
``operation_timeout``. Relative requests above 160 degrees in
magnitude are rejected. If a target is within 2 degrees of either
hardware boundary, it is clamped to the 0--160 degree range; targets
further outside that range are rejected. A displacement smaller than
``minimum_step`` is accepted without issuing a vendor movement.

The result contains ``status``, the resolved serial number, normalized
paddle index, requested relative angle, reported position, and
effective timeout. Movement failures are reported with ``status: ERROR``;
a cancelled context returns ``CANCELLED``.

Fake Driver
===========

Hardware Driver Fake.

Purpose:
- Minimal HardwareDriver implementation used for NodeEngine/DeviceEngine integration testing.
- Provides deterministic signals/parameters and a few long-running tasks.

Notes:
- This driver is intentionally simple and does not attempt to model real device I/O.
- Connection probing is provided via `ProbeConnection()` for monitor-loop testing.

Source: ``DeviceOSPack/OpenDrivers/FakeDriver.py``

FirstForegroundLongPausableTask
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Foreground long task (~120s), pausable and resumable

Example long foreground task with pause/resume support.

Behavior:
- At first start, seeds a random value.
- On PAUSE cancellation, stores current state in _taskPauseStatesByProtocol.
- On RESUME fallback, DeviceEngine injects `_pauseState` and the task continues from there.

Admission policy: ``async``

.. list-table::
   :header-rows: 1

   * - Parameter
     - Type
     - Required
     - Default
   * - durationSec
     - float
     - No
     - 120.0
   * - tickSec
     - float
     - No
     - 1.0
   * - _pauseState
     - Dict[str, Any] \| None
     - No
     - None

Returns: ``Dict[str, Any]``

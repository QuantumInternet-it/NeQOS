PaX000 Driver
=============

.. admonition:: Driver overview
   :class: driver-overview

   :Driver class: ``PaX000Driver``
   :Source: ``DeviceOSPack/PaX000Driver.py``
   :Official product page: `NuCrypt PA1000/PA2000 <https://nucrypt.net/PA-1000.html>`_

.. admonition:: Runtime requirements
   :class: api-reference runtime-requirements

   :Vendor software: No additional vendor SDK declared
   :Python packages: ``pyserial``

   .. rubric:: Local settings
      :class: invocation-heading

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-runtime-settings-table
      :widths: 28 12 25 35

      * - Setting
        - Required
        - Default
        - Description
      * - ``NEQOS_CALIBRATION_DIR``
        - No
        - ``calibrations``
        - DeviceOS-host directory for persisted PaX000 compensated tomography tables. Relative paths are resolved beside the driver module. Set this in the process environment, not DeviceOS.local.json.


   See :doc:`DeviceOS runtime setup <RuntimeSetup>` for local-config discovery and overrides.

Control a NuCrypt PA1000/PA2000 polarization controller.

Hardware capabilities are discovered after connection. Each discovered
channel exposes runtime parameters named ``channel<N>WavelengthNm`` and
``channel<N>Waveplate<M>AngleDeg``. The driver has no ReadSignal surface;
use parameters for live waveplate telemetry and
:ref:`readOpticalConfiguration <deviceos-pax000-readopticalconfiguration>`
for cached optical and compensation data.

:ref:`Network hardware configuration <hardware-config-pax000>`.

:doc:`Driver extension and lifecycle rules </user-guide/writing-hardware-driver>`.

Photek Parameters
=================

.. admonition:: Parameter reference
   :class: api-reference

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-parameter-table
      :widths: 20 15 10 15 12 28

      * - Name
        - Type
        - Unit
        - Range
        - Default
        - Description
      * - ``autoRecoverOnLatch``
        - ``bool``
        - —
        - —
        - ``True``
        - Automatically perform stop/start recovery after an invalid guarded count reading.
      * - ``healthLogEnabled``
        - ``bool``
        - —
        - —
        - ``True``
        - Enable periodic health reads while the driver is ready.
      * - ``healthLogFrequencyHz``
        - ``float``
        - ``Hz``
        - ``0.001 to 10.0``
        - ``1.0``
        - Frequency of periodic health reads while healthLogEnabled is true.
      * - ``integrationTimeMs``
        - ``int``
        - ``ms``
        - ``1 to 65535``
        - ``100``
        - Integration time written to the Photek controller during initialization.
      * - ``maxRecoveryAttempts``
        - ``int``
        - —
        - ``0 to 10``
        - ``3``
        - Maximum automatic stop/start recovery attempts for one invalid health reading.
      * - ``zeroConsecutiveLimit``
        - ``int``
        - —
        - ``1 to 10``
        - ``1``
        - Consecutive guarded readings at or below zeroCountThreshold required to declare a latch.

   .. rubric:: Examples
      :class: examples-heading

   A running micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the requested parameter is advertised.

   Use the parameter table to choose an advertised parameter and a valid value.

   Replace each ``<...>`` placeholder with the appropriate device ID, advertised parameter name, or valid parameter value.

   .. rubric:: Read a parameter from a Python handler
      :class: invocation-heading

   .. code-block:: python

      result = await ctx.get_parameter(
          deviceId="<device-id>",
          name="<parameter-name>",
      )

   .. rubric:: Write a parameter from a Python handler
      :class: invocation-heading

   .. code-block:: python

      result = await ctx.set_parameter(
          deviceId="<device-id>",
          name="<parameter-name>",
          value="<parameter-value>",
      )

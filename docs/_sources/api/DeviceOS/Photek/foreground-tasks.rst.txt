.. _deviceos-photek-initializebiascurrents:

.. admonition:: ``InitializeBiasCurrents``
   :class: driver-overview task-reference

   Apply the full configured detector setup.

   Writes integrationTimeMs, all 16 triggerLevels, and the active bias
   vector, then resets latch tracking. The normal INITIALIZE lifecycle
   operation already performs this same setup.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   No public parameters.

   :Result keys: ``status``

   .. rubric:: Examples
      :class: examples-heading

   The enclosing micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the task is advertised.

   Replace each ``<...>`` placeholder with a value accepted by the corresponding parameter.

   .. rubric:: Static task invocation from a micro-protocol declaration
      :class: invocation-heading

   .. code-block:: json

      {
        "stageId": "<stage-id>",
        "handler": "RunSingleTaskStage",
        "params": {
          "deviceId": "<device-id>",
          "taskName": "InitializeBiasCurrents",
          "taskParams": {}
        }
      }

   .. rubric:: Dynamic task invocation from a Python handler
      :class: invocation-heading

   .. code-block:: python

      reply = await ctx.run_task(
          deviceId="<device-id>",
          taskName="InitializeBiasCurrents",
          params={
          },
      )

.. _deviceos-photek-readdetectorhealth:

.. admonition:: ``ReadDetectorHealth``
   :class: driver-overview task-reference

   Read guarded and all-channel counts, then evaluate latch health.

   A latch is a guarded count at or below zeroCountThreshold for
   zeroConsecutiveLimit consecutive reads. If autoRecoverOnLatch is true,
   invalid reads trigger up to maxRecoveryAttempts stop/start recoveries.
   The returned payload includes readingValid, invalidatesMeasurements,
   latchEventCount, recoveryStatus, counts, and any alert details.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   No public parameters.

      :class: examples-heading

.. _deviceos-photek-recoverlatcheddetectors:

.. admonition:: ``RecoverLatchedDetectors``
   :class: driver-overview task-reference

   Run one manual stop/start recovery cycle.

   channels defaults to latchGuardChannels and is returned in the recovery
   report. Recovery itself disables all 16 outputs, waits recoveryOffSec,
   restores the configured active bias vector, then waits recoverySettleSec;
   it does not selectively power-cycle only the supplied channels.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

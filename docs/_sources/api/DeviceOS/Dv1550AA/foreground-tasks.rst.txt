Dv1550AA Foreground Tasks
=========================

.. _deviceos-dv1550aa-setattenuation:

.. admonition:: ``setAttenuation``
   :class: driver-overview task-reference

   Set and read back the attenuation in dB.

   value must be in the inclusive range 0.00 through 34.00 and aligned to
   0.01 dB. This task is a convenience wrapper around the public
   ``attenuation`` parameter.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

   .. list-table::
      :header-rows: 1
      :width: 100%
      :class: api-table api-task-parameter-table
      :widths: 14 23 10 14 39

      * - Parameter
        - Type
        - Required
        - Default
        - Description
      * - ``value``
        - ``float``
        - Yes
        - —
        - —

   :Result keys: ``attenuation``, ``status``

   .. rubric:: Examples
      :class: examples-heading

   The enclosing micro-protocol must include the target ``deviceId`` in its ``resourceRequests``. NodeEngine retrieves driver capabilities during the device handshake and verifies that the task is advertised.

   Replace each ``<...>`` placeholder with a value accepted by the corresponding parameter.

   .. rubric:: Static task invocation from a micro-protocol declaration
      :class: invocation-heading

   .. code-block:: json

      {
        "stageId": "<stage-id>",
        "handler": "RunSingleTaskStage",
        "params": {
          "deviceId": "<device-id>",
          "taskName": "setAttenuation",
          "taskParams": {
            "value": "<float>"
          }
        }
      }

   .. rubric:: Dynamic task invocation from a Python handler
      :class: invocation-heading

   .. code-block:: python

      reply = await ctx.run_task(
          deviceId="<device-id>",
          taskName="setAttenuation",
          params={
              "value": "<float>",
          },
      )

.. _deviceos-dv1550aa-clearattenuation:

.. admonition:: ``clearAttenuation``
   :class: driver-overview task-reference

   home attenuation captured during initialization.

.. _deviceos-dv1550aa-homeattenuation:

.. admonition:: ``homeAttenuation``
   :class: driver-overview task-reference

   Restore the attenuation captured during driver initialization.

   The home value is initialized from hardwareConfig.defaultAttenuationDb,
   or the default attenuation when that configuration is absent. Later
   changes to the live ``attenuation`` parameter do not replace it.

   :Task class: Foreground
   :Admission policy: ``sync``
   :Pausable: No

SwabianTT Driver
================

HardwareDriver for a single Swabian Time Tagger.

The driver manages:
- physical channels discovered from the device
- logical channels created through Swabian virtual-channel primitives
- synchronized measurements created on those channels
- the subset of active measurements used by the next StartMeasurement window

Implemented task surface:
- CreateLogicalChannel
- CreateMeasurement
- ResetMeasurementEngine
- ActivateMeasurements
- StartMeasurement

Source: ``DeviceOSPack/SwabianTTDriver.py``

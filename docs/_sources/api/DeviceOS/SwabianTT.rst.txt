SwabianTT Driver
================

HardwareDriver for a single Swabian Time Tagger.

The driver manages physical channels discovered from the device, logical
channels created through Swabian virtual-channel primitives, and synchronized
COUNTRATE or CORRELATION measurements. Configured physical channels also
expose runtime parameters named ``channel.<id>.triggerLevelVolt`` and
``channel.<id>.inputDelayPs``.

Measurement definitions remain registered until ResetMeasurementEngine.
ActivateMeasurements selects the subset used by the next StartMeasurement
window. RecordTimeTagStream writes raw selected-channel events as .ttbin.

Source: ``DeviceOSPack/SwabianTTDriver.py``

Official product page: `Swabian Instruments <https://www.swabianinstruments.com/time-tagger/>`_

Exported Tasks
--------------

CreateLogicalChannel
^^^^^^^^^^^^^^^^^^^^

Create a logical channel from existing physical/logical channels using AND, OR, or NOT.

Create or reuse a named logical channel.

AND accepts one or more input references and uses coincidenceWindowPs or
defaultCoincidenceWindowPs. OR ignores coincidenceWindowPs; NOT requires
exactly one input reference. Supplying an existing name with identical
configuration returns its channel reference with ``reused=True``.

Admission policy: ``sync``

ResetMeasurementEngine
^^^^^^^^^^^^^^^^^^^^^^

Reopen the Time Tagger measurement engine and restore physical-channel trigger levels and input delays.

Reopen the measurement engine and discard its derived state.

Logical channels, measurement definitions, and active-measurement
selections are released. Physical trigger levels and input delays are
read before the reset, restored afterward, and returned as readback.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

StartMeasurement
^^^^^^^^^^^^^^^^

Run the active synchronized measurements for a fixed duration and return counts/coincidences.

Acquire all active synchronized measurements for durationSec.

clear resets compatible measurement handles before acquisition. With
rawDataMode ``node``, correlation arrays are returned in the result;
with ``device``, raw correlation data and a preview are scheduled as
device artifacts and artifactWriteState is initially ``pending``.

Admission policy: ``async``

     - No

Returns: ``Dict[str, Any]``

RecordTimeTagStream
^^^^^^^^^^^^^^^^^^^

Record selected channels to one local .ttbin artifact.

Dv1550AA Driver
===============

Control a Thorlabs DV1550AA variable optical attenuator.

The driver configures attenuation, operating mode, wavelength, and VOA
output power through the DeviceOS parameter API. It exposes convenience
tasks for common attenuation operations, but no ReadSignal surface.

Source: ``DeviceOSPack/Dv1550AADriver.py``

Official product page: `Thorlabs <https://www.thorlabs.com/digital-variable-optical-attenuators-dvoas-sm-fiber-coupled>`_

Signals
-------

No readable signals.

Exported Tasks
--------------

setAttenuation
^^^^^^^^^^^^^^

Set the attenuator attenuation in dB.

Set and read back the attenuation in dB.

value must be in the inclusive range 0.00 through 34.00 and aligned to
0.01 dB. This task is a convenience wrapper around the public
``attenuation`` parameter.

Admission policy: ``sync``

.. list-table::
   :header-rows: 1

   * - Parameter
     - Type
     - Required
     - Default
   * - value
     - float
     - Yes
     - -

Returns: ``Dict[str, Any]``

readAttenuation
^^^^^^^^^^^^^^^

Read the current attenuator attenuation in dB.

Read the current attenuation from the hardware.

The returned value comes from GetParameter("attenuation"), which reads
a complete device snapshot before selecting its attenuation value.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

clearAttenuation
^^^^^^^^^^^^^^^^

Set the attenuator attenuation to 0 dB.

Set and read back an attenuation of 0.00 dB.

This changes the live attenuation only; it does not change the stored
home attenuation captured during initialization.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

homeAttenuation
^^^^^^^^^^^^^^^

Restore the configured home attenuation, i.e. hardwareConfig.defaultAttenuationDb from network.json.

Restore the attenuation captured during driver initialization.

The home value is initialized from hardwareConfig.defaultAttenuationDb,
or the default attenuation when that configuration is absent. Later
changes to the live ``attenuation`` parameter do not replace it.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

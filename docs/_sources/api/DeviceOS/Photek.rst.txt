Exported Tasks
--------------

InitializeBiasCurrents
^^^^^^^^^^^^^^^^^^^^^^

Apply configured integration time, trigger levels, and calibrated bias currents.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

StopDetectors
^^^^^^^^^^^^^

Set all Photek SNSPD bias currents to zero.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

StartDetectors
^^^^^^^^^^^^^^

Restore calibrated bias currents on configured Photek SNSPD bias channels.

Admission policy: ``sync``

No public parameters.

Returns: ``Dict[str, Any]``

NeQOS Developer API
===================

Operator guidance and API reference for the NeQOS source tree and matching
executable distributions. Start with the User Guide to install, configure and
run the software; use the API Reference to extend it.

Source code, release archives, and project updates are available in the
`NeQOS GitHub repository <https://github.com/QuantumInternet-it/NeQOS>`_.

User Guide
----------

* :doc:`NeQOS User Guide <user-guide/index>`: installation, network setup,
  protocol runs and results.
* :doc:`LLM Authoring Guide <llm-authoring>`: creating Open
  meta-protocol libraries with downloadable instructions for your LLM.

API Reference
-------------

* :doc:`NodeEngine API <api/NodeEngine/index>`: the built-in meta-protocol
  library, Open libraries and composition handlers.
* :doc:`DeviceOS API <api/DeviceOS/index>`: driver tasks, parameters and signals.

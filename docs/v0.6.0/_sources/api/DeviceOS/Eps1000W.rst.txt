Eps1000W Driver
===============

.. admonition:: Driver overview
   :class: driver-overview

   :Driver class: ``Eps1000WDriver``
   :Source: ``DeviceOSPack/Eps1000WDriver.py``
   :Official product page: `NuCrypt EPS-1000-W <https://nucrypt.net/EPS-1000-W.html>`_

The Eps1000W driver controls a NuCrypt EPS-1000-W entangled-photon source. The parameter surface includes source settings, outputMode and clockOutput, with deployment limits from hardwareConfig. Foreground tasks select the source output and realign it; no signals or background tasks are declared.

:ref:`Network hardware configuration <hardware-config-eps1000w>`.

:doc:`Driver extension and lifecycle rules </user-guide/writing-hardware-driver>`.

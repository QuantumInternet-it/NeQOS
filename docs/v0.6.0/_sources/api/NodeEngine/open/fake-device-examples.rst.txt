Fake Device Examples
====================

Examples on the software-only FakeDriver: built-in stage handlers, local Python handlers, multi-stage/preemptible execution and passing declared results from children to their parent.

Library ID: ``fake-device-examples``

Run the shipped examples
------------------------

Use the matching release and a valid license. Commands below are for a source checkout, from the repository root. For compiled distributions, follow :doc:`/user-guide/quickstart`: DeviceOS uses ``OpenDrivers/OpenDrivers.json`` beside its executable and reads the network using an explicit path to the NodeEngine distribution or a shared JSON. Copying ``NodeEnginePack`` into DeviceOS is unnecessary. Hardware examples can initialize devices and change their state: review serial numbers, optical powers and detector wiring first.

.. dropdown:: composedSweep

   :download:`Download shipped input.json <../../../../NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/MetaProtocolsRun/composedSweep/input.json>`

   Network: :download:`network.json <../../../../NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/network.json>`.

   Start one DeviceOS process for each enabled device below, on its configured host. Wait for connected, initialized and ready state before starting NodeEngine.

   **FakeDeviceId** (``Fake`` driver):

   .. code-block:: bash

      python3 -m DeviceOSPack.DeviceOS \
        --configFile ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/network.json \
        --nodeId FakeNodeId \
        --deviceId FakeDeviceId \
        --licenseFile /path/to/license.json \
        --openDriversFile ./DeviceOSPack/OpenDrivers/OpenDrivers.json

   Then start NodeEngine:

   .. code-block:: bash

      python3 -m NodeEnginePack.NodeEngine \
        --configFile ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/network.json \
        --nodeId FakeNodeId \
        --licenseFile /path/to/license.json \
        --metaProtocolRun ./NodeEnginePack/OpenMetaProtocols/FakeDeviceExamples/MetaProtocolsRun/composedSweep/input.json \
        --waitProtocol

MPC320CountsMaximization
========================

Library: ``ieee-qce-2026-demo``

Open IEEE QCE demonstration wrapper for aligning the polarization incident on the SNSPD of one selected quantum link.

:bdg:`foreground` :bdg:`declared timeout 1 h`

**Lease:** none of its own; child protocols lease the devices they use.

1 Required inputs
-----------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 28 22 50
   :class: api-table protocol-input-table

   * - Input
     - Type
     - Meaning
   * - ``linkId``
     - string length >= 1
     - Quantum link whose SNSPD input polarization is aligned.
   * - ``resourceMpcDeviceIds``
     - string[] (items >= 1; each length >= 1)
     - MPC320 controller identifiers leased by the child alignment. Each item: One MPC320 controller to lease for the alignment.

:doc:`Input defaults and launching </user-guide/running>`.

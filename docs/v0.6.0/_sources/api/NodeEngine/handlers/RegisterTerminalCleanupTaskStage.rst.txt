RegisterTerminalCleanupTaskStage
================================

Register an idempotent device task for terminal cleanup.

Behavior
--------

Register before opening reversible device state. NodeEngine attempts the task on
failure, abort, forced recovery or shutdown while the active lease permits it.
Successful completion does not automatically execute pending cleanup. On the
normal path, verify restoration and clear the matching registration explicitly.
Shared and scratch references are resolved at handler execution.

State and results
-----------------

Registers an executeTask action and persists it in run-manifest.json. Exact
normalized duplicates are deduplicated. No device task runs at registration;
the stage advances. Failed terminal attempts remain visible for recovery.

Failure conditions
------------------

Missing/empty deviceId or taskName, invalid taskParams or unresolved references
fail. An unknown current runtime protocol fails at registration. Registration
does not verify that a future hardware restoration will succeed.

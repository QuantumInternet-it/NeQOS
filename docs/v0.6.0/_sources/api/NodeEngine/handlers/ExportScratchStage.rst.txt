ExportScratchStage
==================

Copy selected scratchpad values into this protocol's exports.

     - Non-empty objects with from (scratchpad path) and as (declared outputSchema export path).

Behavior
--------

Values are validated against this protocol's outputSchema. This handler exposes
exports but writes no result.json. Use PublishResultStage for the final published
result. Shared and scratch references are resolved at handler execution.

State and results
-----------------

Copies values into this protocol's exports and records ExportScratch in
taskResults before advancing. Public output-schema validation includes all
declared keys, not only the mappings passed to this stage.

Failure conditions
------------------

Empty/invalid mappings, missing source values, conflicting destination paths,
unknown current protocol or output-schema mismatch fail without publishing
the proposed export set.

:doc:`Runtime context, decisions and leases </api/NodeEngine/StageRuntime>`.

For the mapping below, the scratchpad must contain holdResult and this protocol's outputSchema must declare execution.control.status.holdDuration; see :doc:`the hold example </user-guide/writing-meta-protocols>`.

          """Copy selected scratchpad values into this protocol's exports.

          Failure conditions:

          try:
              resolvedParams = _ResolveSharedReferences(params, ctx)
          except ValueError as exc:
              return StageResult(decision="fail", reason=str(exc))
          try:
              exports = _NormalizeMappingEntries(resolvedParams, "exports")
          except ValueError as exc:
              return StageResult(decision="fail", reason=str(exc))
          if not exports:
              return StageResult(decision="fail", reason="ExportScratchStage requires at least one export entry.")
      
          pi = ctx.nodeEngine.microProtocolInstances.get(ctx.protocolId)
          if pi is None:
              return StageResult(
                  decision="fail",
                  reason=f"Cannot export scratchpad for unknown protocolId={ctx.protocolId!r}.",
              )
      
          protocolExports = dict(pi.metadata.get("exports") or {})
          exported: List[Dict[str, str]] = []
          try:
              for entry in exports:
                  sourcePath = _NormalizePath(entry["from"], fieldName="from")
                  targetPath = _NormalizePath(entry["as"], fieldName="as")
                  value = _GetPath(ctx.scratchpad, sourcePath)
                  if value is _MISSING:
                      return StageResult(
                          decision="fail",
                          reason=f"Scratchpad path {entry['from']!r} is not available for export.",
                      )
                  _SetPath(protocolExports, targetPath, deepcopy(value))
                  exported.append({"from": entry["from"], "as": entry["as"]})
          except ValueError as exc:
              return StageResult(decision="fail", reason=str(exc))
      
          try:
              ctx.nodeEngine.ValidateProtocolExports(pi, protocolExports)
          except ValueError as exc:
              return StageResult(decision="fail", reason=f"Output schema validation failed: {exc}")
      
          pi.metadata["exports"] = protocolExports
          ctx.taskResults.append({
              "status": "OK",
              "taskName": "ExportScratch",
              "result": {
                  "exports": exported,
              },
          })
          return StageResult(decision="advance")

CompensateSourcePolarizationFromSeparableHDProbes
=================================================

``link.polarizationCompensation``

Compensate both source links from separable H/D tomography and install their tables.

:bdg:`foreground` :bdg:`declared timeout 2 h`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``resourceDeviceIds``.

Compensates each of the two selected emitted links of one entangled-photon source once from factory tomography states and publishes their installed absolute compensation tables without post-installation verification, acceptance thresholds or automatic repetition; COMPLETED denotes operational completion, not certified polarization quality. An explicit latchGuard policy is applied to every acquired window; required includes the network-resolved detector-health devices in the declared resource union.

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 28 22 50
   :class: api-table protocol-input-table

   * - Input
     - Type
     - Meaning
   * - ``deviceId``
     - string length >= 1
     - Entangled-photon source whose two emitted links are compensated.
   * - ``linkIds``
     - string[2] (each length >= 1)
     - Exactly two distinct source-emitted analyzer-equipped links to compensate as one source campaign. Each item: One emitted link identifier belonging to deviceId.
   * - ``resourceDeviceIds``
     - string[] (items >= 4; each length >= 1)
     - Exact source-campaign lease union: source, every source inline attenuator that carrier changes may write, each resolved analyzer, and each resolved TimeTagger. Each item: One unique device identifier in the source-campaign lease union.
   * - ``probeAttenuation``
     - object
     - Total H/D probe attenuation request forwarded unchanged to each composed link campaign in ConfigureQuantumLinkCarrier form. Use perLink to specify the source's two emitted links independently.
   * - ``probeAttenuation.mode``
     - string "common" \| "perLink"
     - Carrier attenuation mode for H/D probes.
   * - ``latchGuard``
     - object
     - Explicit finite-window latch policy propagated to background and tomography acquisitions. required rejects invalid windows and retries only after detector recovery; disabled deliberately acquires without latch protection.
   * - ``latchGuard.mode``
     - string "disabled" \| "required"
     - Whether per-window detector-latch validation is disabled or required.
   * - ``latchGuard.maxWindowRetries``
     - integer >= 0
     - Maximum immediate retries of an invalid window after a recovered latch.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.polarizationCompensation.\ **plan**\ .sourceCampaign
     - Source, two emitted links, analyzer/Time Tagger bindings and lease resources for the separable H/D campaign, with probeTraffic=classical.
   * - link.polarizationCompensation.\ **observation**\ .hdProbesByLink
     - Separable H/D counts, background observations, tomography scans and latch evidence keyed by source-emitted link.
   * - link.polarizationCompensation.\ **estimate**\ .compensationByLink
     - Independent H/D compensation estimates for the source-emitted links whose estimation completed.
   * - link.polarizationCompensation.\ **applied**\ .linkCampaigns
     - Completed per-link table installations with linkId and childProtocolId; every entry has role=target, and earlier completed installations remain listed if a later link fails.
   * - link.polarizationCompensation.\ **applied**\ .referenceFactoryCompensation
     - Always null for separable H/D probes; this protocol does not reset a reference analyzer.
   * - link.polarizationCompensation.\ **status**\ .campaign
     - Campaign outcome, failure reason, requested/completed link counts, child runs and final compensated-H state confirmations; no post-installation quality gate is applied.
   * - link.polarizationCompensation.\ **status**\ .carrierRestoration
     - Per-link outcomes of restoring the source and inline-attenuator snapshots; includes RESTORED, FAILED or UNKNOWN status.
   * - link.polarizationCompensation.\ **artifact**\ .sourceCampaignReport
     - Path to the separable H/D source-campaign JSON report, or null if publication failed.
   * - link.polarizationCompensation.\ **artifact**\ .sourceCampaignCompactReport
     - Path to the separable H/D source-campaign Markdown summary, or null if publication failed.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

     - see Minimal run
     - —
     - Optional fields of this required input.
   * - ``probeAttenuation.commonDb``
     - —
     - >= 0
     - Total attenuation on every emitted source link when mode is common.
   * - ``probeAttenuation.perLinkDb``
     - —
     - —
     - Total attenuation by emitted source link when mode is perLink.
   * - ``measurementDurationSec``
     - 2
     - > 0
     - Finite duration of every singles window used by each link campaign, in seconds.
   * - ``settleSec``
     - 1
     - >= 0
     - Delay after carrier and analyzer-state changes and before the following finite measurement window, in seconds. The default preserves a one-second physical settling interval for analyzer rotations.
   * - ``minTotalCounts``
     - 1
     - >= 0
     - Minimum total background-corrected tomography counts required independently for every H and D probe observation.
   * - ``persist``
     - true
     - —
     - Persist each installed analyzer compensation table on its owning DeviceOS host by default; set false for nonpersistent installations. Persistence does not imply a physical acceptance gate.

RecordTimeTagStream
===================

``acquisition.rawStream``

Record a finite time-tag stream or provide recording lifecycle primitives.

:bdg:`foreground`

:bdg:`Callable from Open libraries`

.. note::

   The device task uses async admission. For a finite recording (operation=record, the default), NodeEngine waits for completion for the greater of 30 s and durationSec + 60 s, allowing for file finalization. The start and stop operations retain the default 30 s completion wait; the async ACK wait remains separate at 10 s. No protocol-level timeout is declared. See :ref:`protocol-timeouts`.

**Lease:** devices selected by ``deviceId``.

Record a finite raw stream from selected physical channels, or provide start/stop lifecycle primitives to a composition that owns the TimeTagger lease-root and guarantees closure.

   * - acquisition.rawStream.\ **plan**\ .recording
     - Requested operation, resolved device/channels when applicable, duration, and caller recording label.
   * - acquisition.rawStream.\ **status**\ .recording
     - Active-stream descriptor returned by operation start; null after record or stop.
   * - acquisition.rawStream.\ **observation**\ .recording
     - Raw successful device recording response, including writer statistics when provided.
   * - acquisition.rawStream.\ **artifact**\ .deviceFile
     - Manifest for the completed device-side raw-stream file set, including the entry file and every numbered data segment; null after start.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 27 18 17 38
   :class: api-table protocol-input-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``operation``
     - "record"
     - "record" \| "start" \| "stop"
     - record completes one finite acquisition. start and stop are lifecycle primitives only for a composition that owns the TimeTagger lease-root: immediately after start it must register terminal cleanup, then stop the same recordingRef on every normal path.
   * - ``channelRefs``
     - null
     - items >= 1; each integer (>= 0)
     - Physical TimeTagger channels written into the stream; required for record and start, ignored by stop. Each item: One physical TimeTagger channel reference.
   * - ``durationSec``
     - null
     - > 0
     - Finite recording duration in seconds; required only for operation record. Must be omitted or null for start; unused for stop.
   * - ``recordingSubdirectory``
     - null
     - length >= 1
     - Optional device-side directory below the driver's recording root.
   * - ``marker``
     - null
     - length >= 1
     - Optional marker recorded by the device with the raw stream.
   * - ``maxFileSizeBytes``
     - null
     - >= 1
     - Optional maximum raw-stream file size accepted by the device.

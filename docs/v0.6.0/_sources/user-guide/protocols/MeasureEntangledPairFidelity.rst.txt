MeasureEntangledPairFidelity
============================

``entanglement.fidelity``

Measure entangled-pair fidelity from guarded tomography of the current optical state.

:bdg:`foreground` :bdg:`declared timeout 2 h`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``resourceDeviceIds``.

Measures Phi+ lab-frame fidelity, the fully entangled fraction, and their fidelity gap from guarded entangled-pair tomography of the current optical state without configuring or compensating the source.

2 What you get
--------------

.. list-table::
   :header-rows: 1
   :width: 100%
   :class: api-table

   * - Export key
     - Content
   * - link.characterization.\ **observation**\ .entangledPairPolarizationCoincidences
     - Unchanged declared 6x6 observation imported from MeasureEntangledPairPolarizationCoincidences, retaining the producer namespace for downstream detected-throughput analysis.
   * - tomography.state.\ **estimate**\ .twoQubitDensityMatrix
     - Unchanged declared physical reconstruction imported from ReconstructTwoQubitDensityMatrix, retaining its producer namespace for downstream state analysis and summaries.
   * - entanglement.fidelity.\ **estimate**\ .entangledPairFidelity
     - Report from EstimateEntangledPairFidelity: labFrameFidelity is Phi+ fidelity in the current laboratory frame; fullyEntangledFraction is the SVD optimum over local unitary frames; frameMisalignmentFidelityLoss is their dimensionless difference, ideally recoverable by local unitary compensation.
   * - entanglement.fidelity.\ **status**\ .tomographyAcceptance
     - Parent acceptance decision, rejection reasons, and references to the validator's runtime, result, and quality report.
   * - entanglement.fidelity.\ **artifact**\ .densityMatrixPlots
     - PNG/SVG paths for labFrame and the theoretical svdFrame, produced once by the fidelity-estimation child and re-exported unchanged; empty when quality rejection prevents estimation.

Every declared key is present after successful completion; its value may be null or empty. Read the keys under ``outputs`` in ``result.json``; see :doc:`/user-guide/results`.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 27 18 17 38
   :class: api-table protocol-input-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 10
     - > 0
     - Finite integration duration for each topology-derived physical coincidence acquisition.
   * - ``settleSec``
     - 1
     - >= 0
     - Delay after each analyzer-state change before its finite coincidence window.
   * - ``coincidenceWindowPs``
     - 1000
     - >= 1
     - AND coincidence window in picoseconds.
   * - ``useCompensatedTomoStates``
     - true
     - —
     - Use installed or loaded analyzer compensation tables. False uses factory tomography states and does not require a table.
   * - ``backgroundCountRateHz``
     - 0
     - >= 0
     - Uniform coincidence background rate applied to every physical pair when backgroundObservation is null; must be zero when a per-pair background observation is supplied.
   * - ``backgroundObservation``
     - null
     - —
     - Optional separately acquired MeasureLinkBackgroundCoincidences observation.background export, containing measurementKind=coincidences and observation with timeTaggerDeviceId, coincidenceWindowPs, measurementDurationSec and countsByPair. Must cover every topology-resolved detector pair with finite non-negative counts on the same TimeTagger and coincidence window. Each physical reading is corrected before symmetrized aggregation. Null selects the uniform backgroundCountRateHz; compensation backgrounds are not imported automatically.
   * - ``pbsReadout``
     - "simultaneous"
     - "simultaneous" \| "symmetrized"
     - Independent tomography readout choice: simultaneous acquires H/D/R on each PBS; symmetrized acquires H/V/D/A/R/L and averages repeated logical projections after detector-pair background correction. Polarizers always acquire six settings. The result is always a 6x6 matrix with counts normalized to one measurementDurationSec window, plus all physical readings and integration times.
   * - ``clear``
     - true
     - —
     - Must be true because required latch protection retries an invalid window as a fresh integration.
   * - ``maxReconstructionIterations``
     - 5000
     - >= 1
     - Maximum maximum-likelihood density-reconstruction iterations.
   * - ``numericLocalUnitaryRestarts``
     - 20
     - >= 0
     - Random restarts for the independent numerical local-unitary Phi+ diagnostic.
   * - ``numericLocalUnitarySeed``
     - null
     - —
     - Optional deterministic seed for the numerical local-unitary diagnostic.
   * - ``dwdmChannelByLink``
     - {}
     - —
     - Optional per-link DWDM channel overrides for analyzer preparation.
   * - ``defaultDwdmChannel``
     - null
     - >= 1
     - Optional fallback DWDM channel when a selected link omits one in network.json.
   * - ``useCompensatedTomoStatesByLink``
     - {}
     - —
     - Optional exact map of both linkIds to boolean table policies. A nonempty map overrides useCompensatedTomoStates, allowing a factory reference and compensated target without changing either policy implicitly.

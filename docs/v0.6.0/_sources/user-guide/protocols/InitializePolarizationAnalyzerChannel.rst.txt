InitializePolarizationAnalyzerChannel
=====================================

``device.initialization``

Initialize an analyzer channel wavelength and factory tomography state for a link.

:bdg:`foreground` :bdg:`declared timeout 5 min`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``paDeviceId``.

Initializes one polarization-analyzer channel for a quantum link by setting its DWDM wavelength and an uncompensated tomography state.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 27 18 17 38
   :class: api-table protocol-input-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``paChannel``
     - 1
     - >= 1
     - One-based analyzer channel; set null to infer it from the link binding. Null resolves the channel from the link binding; omission keeps the catalog default.
   * - ``dwdmChannel``
     - null
     - >= 1
     - Optional explicit DWDM wavelength selector; null derives it from the link.
   * - ``initialTomographyState``
     - "H"
     - length >= 1
     - Uncompensated tomography state to apply after setting the wavelength.
   * - ``settleSec``
     - 0.2
     - >= 0
     - Delay after the analyzer has accepted its configuration.

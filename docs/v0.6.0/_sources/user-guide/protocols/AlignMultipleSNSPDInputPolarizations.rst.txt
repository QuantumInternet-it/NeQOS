AlignMultipleSNSPDInputPolarizations
====================================

``link.polarizationAlignment``

Align multiple SNSPD input polarizations using parallel MPC320 scans and count-rate feedback.

:bdg:`foreground` :bdg:`declared timeout 40 min`

:bdg:`Callable from Open libraries`

**Lease:** devices selected by ``deviceIds``.

Align the input polarizations incident on multiple SNSPDs by scanning their associated MPC320 controllers in parallel and using simultaneous TimeTagger count-rate feedback.

3 Options
---------

.. list-table::
   :header-rows: 1
   :width: 100%
   :widths: 27 18 17 38
   :class: api-table protocol-input-table

   * - Input
     - Default
     - Allowed
     - Meaning
   * - ``measurementDurationSec``
     - 0.2
     - > 0
     - Integration duration for each simultaneous count sample, in seconds.
   * - ``optimizationMode``
     - "maximize"
     - "maximize" \| "minimize"
     - Whether each controller angle is selected to maximize or minimize its linked SNSPD count rate.
   * - ``initialPositionMode``
     - "explicit"
     - "explicit" \| "current"
     - Whether all selected paddles are moved to initialAnglesDeg before scanning, or remain at their current positions until their individual coarse scans begin.
   * - ``paddles``
     - [0, 1, 2]
     - items >= 1; each integer (>= 0)
     - MPC320 paddle indices to scan on every selected controller. Each item: One MPC320 paddle index.
   * - ``initialAnglesDeg``
     - [0, 0, 0]
     - items >= 1
     - Initial scan angle for each selected paddle, in degrees.
   * - ``finalAnglesDeg``
     - [160, 160, 160]
     - items >= 1
     - Final scan angle for each selected paddle, in degrees.
   * - ``stepDeg``
     - 10
     - > 0
     - Coarse scan angular increment in degrees.
   * - ``refinements``
     - []
     - each object
     - Ordered optional whole-controller passes; each pass scans every selected paddle around the corresponding preceding-pass optimum and is bounded by the coarse scan endpoints. Each item: One refinement-pass configuration applied to every selected paddle on every controller.
   * - ``refinements[].halfRangeDeg``
     - —
     - >= 0
     - Half-width of each paddle scan around its preceding-pass optimum, in degrees. Include this field in each ``refinements`` item.
   * - ``refinements[].stepDeg``
     - —
     - > 0
     - Angular increment for this local scan, in degrees. Include this field in each ``refinements`` item.
   * - ``settleAfterMoveSec``
     - 0.2
     - >= 0
     - Settling delay after every parallel controller movement, in seconds.
   * - ``moveTimeoutSec``
     - 30
     - >= 0
     - Timeout for each MPC320 movement, in seconds. Null requests no per-move timeout override.
